**入口：** 中文版 [pokeamice.com/designers/](https://pokeamice.com/designers/) · Docs 版 [/credits/designers/](/credits/designers/)

整理每只宝可梦的主设计者。底稿是 gfworks 的 Pokémon Primary Designers 表，再用 Docs 的[制作名单](/credits/)逐条核对，补上其他出处（例如设计者本人在社交网站上的说明）。

## 两种看法

- **按设计者**：选一位设计者，列出他负责的全部宝可梦。
- **按图鉴编号**：按世代排开，每只宝可梦标出设计者。

页面上的世代矩阵可以一眼看出每位设计者主要活跃在哪几个世代。

## 出处

每一条都有出处。gfworks 原表和本站名单一致的直接标注；只在一处出现、或来自补充来源的，单独列在页面底部的出处表里，可以点开原始链接核对。

## 两个版本有什么不同

主站 /designers/ 和 Docs /credits/designers/ 用的是同一份数据。主站版把宝可梦图标换成了本站图床，方便国内访问；Docs 版可以直接跳到对应的制作名单页。
