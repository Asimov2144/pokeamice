**入口：** [pokeamice.com/image-search/](https://pokeamice.com/image-search/)

在宝可梦友会的站内图片里查找：媒体库、NextGEN 图库和游戏截图。可以搜图片名称、标签、文件名或所在图库，宝可梦名用常用译名就行。

## 怎么用

1. 在搜索框输入关键词，按「搜索」。没想好搜什么，可以点下面「快速试试」里的皮卡丘、道具、USUM、官方插画、像素素材、游戏截图。
2. 用「图片来源」缩小范围：全部、媒体库、NextGEN 图库、游戏截图。再用「年份」筛选。
3. 点图片看大图。如果这张图出自站内某篇文章，卡片底部的「返回原文 →」会带你回到那篇文章。

## 卡片上写了什么

| 位置 | 内容 |
| --- | --- |
| 左上角标签 | 图片来源（媒体库 / NextGEN 图库 / 游戏截图） |
| 右上角 | 上传日期 |
| 标题与文件名 | 图片标题和原始文件名 |
| 分类路径 | 例如「官方插画 > RG POKEART」「道具 > pixel」 |
| 命中方式 | 「标题命中」「替代文字命中」等，说明这张图为什么出现在结果里 |

## 名字怎么匹配

- **常用译名和别名**：宝可梦名会展开成别名一起搜，旧译、俗称也能找到。
- **繁体和简体**：两种写法都能命中同一只宝可梦。
- 检索范围只有宝可梦友会自己的图片，不搜外站。

## 限制

- 新上传的图片要等夜间索引重建之后才搜得到。
- 按图鉴编号、宝可梦这类结构化条件筛选，依赖图片已经标注过；没标注的图片只能靠名称和文件名命中。
