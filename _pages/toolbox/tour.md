**入口：** [pokeamice.com/tour/](https://pokeamice.com/tour/)

把和宝可梦有关的真实地点放在一张地图上：宝可梦中心、宝可梦井盖、官方道馆、打卡地、商店和餐厅、公园、活动会场、历史配信地点、历史遗迹和限定设施。

## 地图上有什么

- **顶部分类**：全部分类、宝可梦中心、井盖、官方道馆、打卡地、商店 / 餐厅、公园 / 自然、活动、历史配信、历史遗迹、限定设施。右边的数字是当前显示的地点数和总数。
- **地区气泡**：远看时按地区聚合（东北、关西、九州……），点进去展开这个地区的地点。标着 NEW 的地区最近有新地点。
- **底部时间切换**：在「现在」「历史」「全部」之间切换要看的时间范围（「历史」旁的数字是历史地点数）。「讲解」进入讲解模式：选一个主题，按站逐个讲这一带的宝可梦历史。

## 左侧功能栏

桌面版左边一列按钮，鼠标停在上面会显示说明：

| 按钮 | 用途 |
| --- | --- |
| 视图 | 打开 / 收起右侧的阅读面板 |
| 活动 | 在地图上用站号牌标出活动地点，阅读面板里显示对应注脚 |
| 地区 | 按地区浏览 |
| 聚合 / 散点 | 地点多时聚成气泡，或者全部散开显示 |
| 官方 / 社群 | 切换只看官方地点，或看社群投稿的地点 |
| 随机 | 随机去一个地方 |
| 投稿 | 快速投稿一个新地点 |
| 行程 | 行程规划 |
| 专题 | 专题收集图鉴：宝可梦井盖、宝可梦中心 |
| 帮助 | 帮助指南 |

## 交给 Google 地图

- 地点资料页的页头有导航键，可以直接交给 Google 地图导航。
- 地区页「这里有 · N 处」那一行右边有「在 Google 地图里看」（日本以外的地区叫「导出到 Google 地图」）。点开先看到站主维护的公开 Google 地图，手机一点就能打开；想按当前筛选只带这些地点、或者存进自己的地图，可以「下载 KML」，再导入 Google「我的地图」。Google 地图本身不能用一个链接一次导入一组地点，所以要走 KML 这一步。
