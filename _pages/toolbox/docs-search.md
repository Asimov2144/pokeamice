## 入口一览

| 入口 | 适合 |
| --- | --- |
| [站内搜索](/search/) | 知道关键词时直接搜，例如人名、刊物名、作品名；可以按类型筛选，例如[只看扫描翻译](/search/?type=%E6%89%AB%E6%8F%8F%E7%BF%BB%E8%AF%91) |
| [人物索引](/entities/people/) | 从一位开发者、配音员或作者出发，看他出现在哪些资料里 |
| [作品库](/works/) | 从一部游戏、动画或电影出发，看相关资料 |
| [制作名单](/credits/) | 查各作品的制作人员名单，按职能、时代对照 |
| [组织索引](/entities/organizations/) · [事件索引](/entities/events/) | 从公司、媒体或一次活动出发 |
| [资料时间线](/timeline/) | 按年份看当年有哪些资料，以及那几年的代表作品 |
| [关系图谱](/resource-graph/) | 看人物、作品、组织之间怎么通过资料连起来 |

## 怎么挑入口

- 只知道大概内容：先用**站内搜索**。
- 想了解一个人：**人物索引**，人物页有不同时期的照片和相关资料。
- 想看一部作品的开发故事：**作品库**找到作品，再看它的**制作名单**。
- 想知道某一年发生了什么：**资料时间线**。
