## 怎么读

打开一篇资料后，左边是扫描页，右边是按阅读顺序排好的段落。

- **点扫描页上的区域**，右边会跳到对应段落；**点右边的段落**，扫描页会定位到原文位置。
- **双击扫描图**可以快速放大；也可以用「−」「＋」调整缩放，或打开「查看完整原图」。
- 页面顶部的「本页导读」写着这一篇讲什么、分了几个阅读区。

## 阅读方式

| 方式 | 适合 |
| --- | --- |
| 研究模式 | 原刊和译文并排，逐区核对 |
| 原刊＋选区 | 只看扫描页，划出的阅读区高亮 |
| 只看日文 | 读 OCR 出来的日文原文 |
| 只看中文 | 只读译文 |
| 阅读版 | 去掉扫描页，按文章排版连续阅读 |

## 资料状态

每篇资料都标着复核进度。例如试读这篇标的是「资料试读 · 初译待终审」：扫描页和原文对照都在，但专有名词、译文以及公开权利状态还在等最终人工复核。
