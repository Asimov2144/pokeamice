**入口：** [pokeamice.com/event/](https://pokeamice.com/event/)

收录宝可梦的线下活动、游戏内活动、商品发售、人物生日和「历史上的今天」。可以按今天、按月、按时间线来看，看中的活动可以排进自己的日程。

## 三种看法

页面右上角切换：**Feed**（资讯流）、**月历**、**动态**。

Feed 上方的分组按钮：

| 分组 | 内容 |
| --- | --- |
| 宝事 · 资讯流 | 今日进行时、一周回顾、本周预告混合排序 |
| 现在 · 接下来 | 正在进行和即将开始的活动 |
| 橱窗 · 商品 | 商品发售 |
| 纪念与历史 | 生日、开业纪念、历史上的今天 |
| 全部 | 不分组 |

「推荐范围」可以调整资讯流收哪些内容。

## 常用功能

- **搜索**：左侧栏「多搜宝事，会有好事」，也可以点「推荐标签」，例如 #生日、#动画、#宝可梦中心。
- **我的日程**：在活动卡片上点「日程」加入，在右上角「我的日程」里查看。日程保存在你自己的浏览器里，换设备或清除浏览器数据会丢失。
- **宝事长图**：顶部「查看长图」或左侧「宝事长图」，把今天的宝事排成一张长图，方便分享。
- **只看收藏**：左侧勾选「仅显示收藏的宝事」。
- **旅行地图**：顶部「旅行地图」跳到[宝可旅图](/toolbox/tour/)，在地图上看活动会场。
- **日本語**：顶部可以切换日语界面。
- **记录事件**：发现没收录的活动，可以用「记录事件」投稿，审核后公开。

## 数据从哪里来

活动来自官方公告、官方社交账号和投稿；历史配信、会场等部分资料引用自神奇宝贝百科（CC BY-NC-SA 3.0），引用的条目会标注出处。
