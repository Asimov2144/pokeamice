# 微博碎片：软木看板、图钉便签与贴纸

## 依据与范围

- 用户明确选择「软木看板＋图钉便签」。这是这次视觉方向的依据。
- `design/README.md`：区分页面结构、资料自身的形式和宝可梦局部线索；Source Shelf 将资料视为可收藏的实体；保留清晰的信息层级，不能用装饰替代结构。
- 原始碎片页提交 `05a48d79`：照片保留比例；保留 hero、float、polaroid、tape、pair、overlap、film strip、grid、mosaic、图文混排等编排；四种便签纸；每个图标独立成为贴纸；图边及纸边预留贴纸位置；每月保留一份双栏剪报。
- `design/weibo-longform-reading-2026-10-18.md` 明确排除了碎片页。因此，不将普通长文阅读器的统一白底版式套在碎片上。
- frontend-dev 用于组件比例、可读性、焦点、响应式、动态效果检查；沿用 Jekyll、现有 CSS 与原生 JavaScript，不引入框架。无新照片或角色图，材质采用本地 SVG，内容图片和角色继续使用已有素材。

范围仅为 `/notes/weibo/`。访谈、原创长文、内容数据与图片地址不变。

用户后续反馈图片不需要额外解说：收缩与展开均不展示模型生成的配图说明和 OCR 摘要。这些信息保留为检索数据；原帖文字、配图、原帖链接与视频未收录提示继续展示。

## 视觉规则

| 层级 | 应有的视觉表现 | 避免 |
| --- | --- | --- |
| 底板 | 中等明度暖棕软木、细小不规则木屑纹理、浅木边框；留出图钉和纸边的空间 | 白色空背景、橙色大色块、布面纹理 |
| 纸张 | 薄纸边、纸纤维、轻微色差，阴影统一向右下；米白、淡黄、粉、蓝、横线纸 | 带主题色顶边的普通网页卡片、巨幅纯色矩形 |
| 固定方式 | 纸顶的圆形图钉，有头部高光、短钉影；照片可以保留胶带和相纸边 | 漂浮的纸、没有落点的大阴影 |
| 分类纸签 | 小纸签、切角、少量分类色和深色文字，日期像纸上的印记 | 与筛选按钮相同的圆角胶囊 |
| 照片 | 原比例、真实相纸白边、胶带、叠放或剪报结构；各版式保留差异 | 统一裁切、所有图片变成同一个相册网格 |
| 贴纸 | 透明轮廓外的薄白模切边与接触阴影；每枚独立、轻微倾斜，可压住纸/照片边缘 | 圆角白色 App 图标底座、漂浮头像、连续整排徽章 |

阴影、纸纤维和木屑均应在正常浏览比例下可辨认，不能依赖截图放大才看得见。贴纸尺寸以便签宽度为参照，在桌面约 52–72px，手机保持约 48–64px；不遮日期、正文、原帖链接和展开入口。

素材检查发现，作品图标本身含有圆角白底，不能只去掉 CSS 底座就声称得到异形贴纸。作品图标使用小型剪齿纸边承托，作为邮票式作品标签；透明的宝可梦角色图才沿真实轮廓呈现模切白边。保留原图，不抠掉原画中的白色，也不凭空改画官方素材。

## 两种状态

收缩状态是看板上的小便签和照片剪贴，不是文章阅读器。保留原始编排与内容前后关系，正文可显示摘要；分类纸签、图钉、照片处理和贴纸必须能被看出。筛选控件放在看板外，维持标准控件的可识别性。

展开状态直接使用同一张纸的完整结构：纸张、图钉、分类签、贴纸、照片处理、图文混排均保留。只放宽阅读区域、解除正文截断并展示额外配图，模型解说与 OCR 摘要继续隐藏。长纸张的外框摆正以避免横向溢出，内部照片与贴纸的角度保留。收起控件是独立的小纸签，不增加通用弹窗标题栏和白底容器。

## 可读性与验收

- 小便签正文至少 15px、约 1.7 行高；展开正文 18px 左右、约 1.85 行高；文字保持深墨色。图注与日期保持可读，不能依赖低透明度。
- 手机单列便签，软木和纸边仍有空间；320px 与 390px 不横向溢出。图片不拉伸、不裁掉原内容。
- 保留键盘展开、Esc 收起、焦点返回与原筛选条件。链接正常工作，文字可以选择。没有循环、视差或滚动动画。
- 用普通图片便签、彩色无图便签、图文混排和超过 6 图的旧帖，分别核查收缩与展开。
- 比较贴纸、照片、图注与正文的数量及顺序；确认 983 条原内容和原帖链接不变。
- 人工看真实页面截图，确认软木、图钉、纸签、照片和贴纸各自可辨；不能只以 DOM 元素存在作为设计通过的依据。
