# 资料时间线改版

日期：2026-09-30。范围仅为 `/timeline/` 与 `/timeline/<year>/`，不修改正式首页，也不修改访谈模版预览 index。

## 设计依据

已完整对照 `design/README.md` 与 `design/pokeamice_interview_reading_ui_redesign.md`。

- Archive Index：让时代、年份、月份和标题构成稳定目录，而非普通推荐卡片墙。
- Source Shelf：使用真实原刊页、封面与人物资料图，呈现资料自身的特征。
- Modern Quietness：低饱和纸色、深墨色、单一砖红强调；用层次和分隔线代替大量圆角卡片。
- 阅读 → 发现 → 档案：年份页先呈现可阅读的资料，作品与人物关联收入侧边折叠区。

frontend-dev 的可读性与质量要求用于响应式布局、键盘焦点、对比度、无结果状态和减少动态效果。沿用 Jekyll / Liquid / Sass / 原生交互，不引入框架或新增依赖。

## 总览

首屏有时间线说明与一篇真实访谈选读。田尻智的照片来自人物资料库，图下单独注明出处，不声称为 TIME 1999 访谈配图。

年度图将文献与博客分开；两组柱高分别按各自最大年份归一化，并在图例明确说明，避免数量多的博客掩盖文献，也避免柱形越界。手机只在图内横向滚动，整页保持单列。

年代目录沿用资料表的六段划分，使用完整中文作品名称。每年展示最近发表的两篇文献，作为进入该年的入口，不暗示质量排名或全文覆盖；完整资料进入年份页阅读。

## 年份页

资料按发表日期从早到晚排列，按月分组，以日期、类型与来源、标题、摘要、人物、缩略图组成连续条目。完整标题保留；没有图片也能自然阅读。

博客按原栏目折叠，默认与文献分开，不会把数百篇手记混进文献的月份目录。

增强交互包括：

- 年份选择与前后年份导航。
- 手机上把年份选择与背景信息收入一个原生折叠入口，月份目录继续直接显示；桌面则保持边栏展开。
- 标题、来源、人物、作品及摘要的关键词检索；多个词同时匹配，不搜索访谈全文。
- 访谈与报道、原刊扫描、官方专题、文章、开发者博客筛选。
- 动态结果数、月份计数、无结果提示与清除入口。
- 筛选后同步隐藏空月份及其导航，不留下失效锚点。
- 搜索博客时展开匹配栏目，清除后恢复之前的折叠状态。
- `?k=scan&q=...` 等可复制的查询地址；切换年份保留查询与类型，若目标年没有该类型则回到全部。
- 当前章节标记、明确输入标签、键盘焦点、手机触控目标与减少动态效果。

全部内容直接由 Jekyll 生成。没有远程数据加载，所以不设置虚假的加载动画；禁用 JavaScript 时仍能读到全部资料，原生链接与折叠仍可使用。初始化失败则恢复全部内容并显示提示。

## 数据与素材

旧总览依赖 `_data/timeline.yml` 的提交快照，当前本地旧值为453篇文献；年份正文却读取工作区文章。新总览、柱图、年份正文和筛选计数统一使用当前参与 Jekyll 构建的文章：475篇文献、710篇博客，共1185篇记录。

`timeline-kind.html` 是分类的单一入口，`timeline-counts.html` 同时生成显示列表与计数。`search: false` 的非博客条目排除；博客仍纳入。Jekyll 负责 unpublished / future 等发布规则，不从文件数量推断已部署数量。

年代划分、发售作品与人物关联仍复用既有资料表；人物折叠区明确说明关联数据不等同本页搜索结果，未自动改写历史资料表或人物出现次数。

缩略图只使用已有本地素材。`_data/timeline_thumbnails.yml` 为12个外部图库地址提供同一原刊页的已核验本地副本映射；无对应本地图片的条目采用文字排版，不拿其他人物或刊物图片替代。原文章、原刊图片地址与正文完全保留，未下载或重新发布额外图片。

## 验证与预览

使用真实 Jekyll 渲染总览与30个年份页；局部构建输出位于 `.preview-build/timeline/`，不覆盖正式输出。访谈选读也生成其现有阅读器页面，方便从总览进入。

- 渲染：`ruby tools/preview_timeline.rb`
- 数据与结构：`python -m unittest tools.tests.test_timeline -v`
- 浏览器：`node tools/tests/check_timeline.cjs`
- 本地预览：`node tools/tests/check_timeline.cjs --serve`，打开 `http://127.0.0.1:8763/timeline/`。

- 248组浏览器版面检查通过：31个路由 × 1440 / 1024 / 390 / 320 宽度 × 明暗主题，未发现横向溢出、柱图越界或被测文字低于4.5:1的对比度。
- 另实测类型筛选、搜索与清空、无结果重置、深链接、年份跳转、手机折叠入口、进入访谈及禁用脚本阅读。
- 桌面总览、年代目录、手机连续条目与暗色年份页截图已人工复核。
- 已确认当前资料无晚于2026-09-30的记录；预览启用 future 不造成此次计数偏差。

保留既有 Sass 弃用提示，不将其误报为编译失败；本次不是全站发布或部署。局部预览包含全部时间轴页面与选读访谈，不生成全站其他文章、人物和制作名单页面；这些链接对应真实源内容，在正式构建中提供。
