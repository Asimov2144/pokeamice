## 三、站内现有帖子的问题

**1. 10 篇的日文「原文」是编出来的。** 帖子 `parallel_items` 里的日文段落，开头几个字和页面一样，后面却是另写的，事实也改了（例：页面写「2015年に入社」「CG部門でプログラマ」，帖子写「2014年に…入社」「デザイン・制作を担当」）。全段原样能在存档里找到的比例：

| 帖子 | 原样 |
|---|---|
| 2015-08-01 gear-tembo-turner | 13/22 |
| 2015-10-01 recruit-designers | 9/22 |
| 2015-10-01 recruit-planners | 9/19 |
| 2015-10-01 recruit-programmers | 10/24 |
| 2017-03-01 gear-gigawrecker | 9/22 |
| 2017-06-01 rnd-ta-taya-kk | 8/17 |
| 2017-09-01 recruit-cross-industry | 9/25 |
| 2021-12-27 crosstalk-game-programmer | 4/20 |
| 2021-12-27 crosstalk-new-graduate | 3/21 |
| 2021-12-27 crosstalk-system-programmer | 4/18 |

其余 21 篇（2013 两篇、2015-09 研究开发部、2019 两篇、12 篇人物、设计 / 策划 / 程序 / 世界观对谈）是可靠的；对谈那几篇差的 1–2 段是编者把真名（「大森 滋 / Shigeru Ohmori」「谷博行」）写进了原文的成员介绍，页面上只有首字母。这些认定本身有依据（如设计对谈 H.T. =《阿尔宙斯》CG 总监 = 名单里的 Haruka Tochigi），只是不该写进原文。

**3. 分类与字段。** 游戏程序员 / 系统程序员 / 新卒若手 三篇不在 `gamefreak-recruit` 分类；两篇对谈的 `interviewee` 带了「档案」；多篇摘要写「2021 年」。
