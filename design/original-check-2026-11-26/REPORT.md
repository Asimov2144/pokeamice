# 原页机械扫描（2026-11-26）

`sweep.py`：对 505 篇双语帖里有来源网址的 418 篇（首藤 87 章上一轮已逐段核过、不在内）抓取来源页，逐行算「原文」6-gram（拉丁文 12-gram）覆盖率；`fetch` 抓页、`score` 打分、`triage` 看页长 / 覆盖，`para.py` 找「在页上有近似段落、但文字对不上」的改写行，`show.py` / `pages_dump.py` 并排看。页面缓存 `sweep/pages/` 不入库。

## 结果

- 能打分 297 篇；121 篇没抓到可用页面（多为已下线 / 动态页 / 会员限定，Wayback 抓取超时），**未核**。
- 82 篇有低覆盖行，绝大多数是「页面只抓到一部分」（分页、会员限定、页面已改版——例如 GAME FREAK 招聘对谈现行页是新版），不是帖子的问题。
- 真正的「页面完整、但帖里的原文是改写 / 编造」只在两篇英文访谈里：
  - **Pokemon.com 究极之日·究极之月访谈**（岩尾和昌 × 大森滋，取 PocketMonsters.net 转载）：38 行里 14 行是改写，含「第 n 节」编造小标题、对战 UI / 纸质等编造内容。已按原页重建 50 行（含 7 个原页小节名作标题），重写 title / subtitle / summary，今日一句 3 条与图鉴观察 2 条同步。
  - **Eurogamer 增田 × 大森访谈（葱游兵）**：17 行是改写，其中「去英国考察时吃炸鱼薯条、司康饼、坐蒸汽火车」整段是编的；增田答话的顺序也错了。已按原页重写 17 行、补漏掉的编辑说明段、调整顺序、删掉两条无原页依据的译注、重写 summary / title，今日一句与观察同步。
- 其余（nintendolife、eurogamer 黑白、game informer 动画、sankei、nikkei 等）低覆盖行在页面上找不到对应段落，判断为页面不全（分页 / 会员限定），没改。
