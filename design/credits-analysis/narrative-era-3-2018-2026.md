# 2018–2026 历作 staff 名单分析：Let's Go → 剑盾 → 阿尔宙斯 → 朱紫 → 零之秘宝 → Z-A → Champions

> 材料：`era-3-2018-2026.md`（逐作变动、职务矩阵、类别人数）、`absences.md`、`sections.md`；个别人的英/日职务原文用 `people.json` 核对。所有推断只基于这些表。表外的公开信息（某人是否已公开离职、某开发商是谁）一律标"待核"，不作为论据。
> 级别记号沿用原表：`*` lead，`^` section/art/program director，`!` director/producer，`!!` executive producer。"缺席、之后回来"= 该作没出现、后作又出现；"之后再没出现"= 前一作在、从该作起任何核心作都不在。

## 一、团队结构：从一个团队到"两个企划团队 + 共享工厂"

**规模**（不含公司、纯 Thanks）：Let's Go 359 → 剑盾 650 → 阿尔宙斯 543 → 朱紫 891 → 零之秘宝 672 → Z-A 805 → Champions 339。Loc/QA 一列（152/190/159/184/200/195/159）基本是 Nintendo/TPCi 人员且全期稳定，扣掉它和 Thanks，Game Freak 侧（Plan+Prog+Art+Sound+Mgmt+Other）约为 190 → 441 → 362 → 669 → 434 → 559 → 144。四年翻三倍；2022 年阿尔宙斯与朱紫合计 1031 人次，说明并行时两条线各自都是完整规模，不是一主一副。

**类别比例的三个变化**

1. Art 成为绝对主体：98 → 243 → 240 → 353 → 297 → 379。来源有两块。一是剑盾开始出现的外包：`3D Graphics Section Cooperative Companies` 下的 Silver Ant PPI Sdn. Bhd.（马来西亚），以及只出现在剑盾的一批外籍建模师（Chua Pei San、Liew Hoi Leong、Suresh Kumar、Prakhar Bhatnagar、Dhavanessh Soundararajan）。二是 2022 年起固化的 `Pokémon 3D Modeling / Pokémon Character Modeling・Motion` 群体：约 80 人在阿尔宙斯、朱紫、零之秘宝、Z-A 四作全勤（Ai Yuda、Asami Hamamori、Kento Nishimatsu、Kim Won……矩阵里整齐的"4 作，2022–"），Champions 全部缺席。管理层是 Atsuko Ujiie（氏家淳子，Art Director，剑盾→Z-A 五作职务不变）、Kengo Nakahiro（中廣健吾，Project Director）、Masamichi Anazawa（穴澤匡道，Product Manager）、Shun Onodera（Pokémon Character Modeling lead → Project Director）。Ujiie、Anazawa、Nakahiro 三人同时出现在 new-pokemon-snap(2021) 与 detective-pikachu-returns(2023) 的外传名单，说明这个单元也对外部作品供模——它是跨企划的宝可梦模型工厂。
2. Plan 的两个尖峰是分类假象：剑盾 73、朱紫 120，而阿尔宙斯 25、零之秘宝 31。脚本把剑盾的 `World Concept Section` 与朱紫的 `Design & World Concept / Concept Art` 整段归 Plan，同一批设计师（Emi Ando 安藤絵美、Fumie Kittaka 橘高文美恵、Hironobu Yoshida 吉田宏信、Kyoko Abe 阿部杏子、Misaki Hashimoto 橋本美咲、Tomomi Kaneko 金子智美、Seimi Ohshiro、Huang Tzu En、Atsuko Nishida にしだあつこ、Hitoshi Ariga ありがひとし、Take 竹）在阿尔宙斯和零之秘宝被归 Art，矩阵上呈现 Plan/Art/Plan/Art/Art/Plan 的逐作翻转。剔除后真正的 Planning Section 约 20–45 人。
3. Prog 的下跌大半是命名变化：朱紫 130 → 零之秘宝 48 → Z-A 42。Z-A 把许多程序团队写成"…Team"，脚本归入 Other（Other 从 4 涨到 24）：Kazumasa Iwao 的 Pokémon Attribute Team、Takuto Takabe 的 Communication Features Team、Ryota Takeuchi 的 Library Team、Nobuyuki Miura 的 Simulation Team、Tomoya Kanehira 的 DCC Environment Development Team、Masamu Ishizuki 的 Machine Learning Team；另一批程序/企划被写进 `UI Team` 归 Art（Tōru Nagihashi 名木橋徹、Tetsuji Ōta 太田哲司、Masayuki Kawabata、Yusaku Koda、Masayuki Mitsueda）。

- Z-A（2025）：CGテクノロジーラボ的三位"Directors"（Maezawa、Goto、Masashi Kida）、Pokémon Attribute Team（日页原名"ポケモンシリーズQA / ポケモンパラメータチーム"）、Pipeline Team、Rigging System Development Team、Game AI Team、Character & Costume Design，Product Managers 并入 Mgmt（Mgmt 40，本段最高）。

## 三、"缺席、之后回来"：每一次缺席都指向另一条线

- **LGPE（2018）缺席 69 人 → 剑盾回归**：Iwao、Shigeki Morimoto（森本茂樹）、Tomoya Takahashi、Nakatsui、Mana Ibe（井部真那）、Anazawa、Ichiraku、Ujiie、Nakahiro、Masataka Hata（畠祐貴）、Tani、Kuninobu、Gō Ichinose（一之瀬剛）、Toshinobu Matsumiya（松宮稔展）、Minako Adachi（足立美奈子）、James Turner……即 USUM 团队整体跳过 Let's Go 直接做剑盾。Let's Go 由 Masuda 带一批老兵回归（Masafumi Saitō 上次 ORAS、Nagihashi／Ikeuchi／Onoue／Tamada 上次 SM、Shōta Kageyama 景山将太上次 ORAS）。**双团队并行在 2017–2018 就是事实**，只是当时一条线是外传级别。
- **剑盾（2019）缺席 → 阿尔宙斯回归**（去掉 Loc/QA 后仅 6 人）：Onoue（Prog* → 阿尔宙斯 Prog^ Programming SD）、Ikeuchi（Prog^ → Framework Team）、Tochigi（3D Map → CG Director）、Kawazoe、Koji Kawada、Kojiro Matsuyama。这是阿尔宙斯在 2019 年前的种子团队：清一色程序/CG，说明阿尔宙斯先做的是开放地形的技术原型，企划核心（Iwao、Murase）在剑盾交付后才进入。

- **朱紫（2022-11）缺席 13 人 → 之后回归**：Iwao、Murase、Hideki Iwata、Matsumiya、Yuya Watanabe（→ Champions "ILCA,Inc. / Game Planners"，是否同名待核）——阿尔宙斯独有的企划核心，没有并入朱紫。

## 四、双团队并行的分线判定

**阿尔宙斯线 vs 朱紫线（2019–2022）**

- 阿尔宙斯：Director Iwao；Programming SD Onoue；Planning SD Murase；Graphics SD Unno；CG Director Tochigi；Environment SD Syo Araki；CG Technology SD Maezawa、Jun ITO；Main Scenario Matsumiya；种子成员 Ikeuchi、Kawazoe、Kawada、Matsuyama；Story Team Yuya Watanabe。
- 朱紫：Director Ohmori；Planning SD Tani；Game Programming & UI SD Ichiraku；System Programming SD Tomoya Takahashi；AI SD Saita、Shun Yamashita；Physics SD Kawazoe（阿尔宙斯后转入）、Daiki Tanaka；3D Graphics SD Maiko Fujiwara；Art Director Ibe；Design & World Concept SD Nakatsui；Battle Hiroto Ito（伊藤博人）、Morimoto；Field Muroi、Asaoka、Murayama；UI Kensaku Sanda、Erika Kuga（久我絵理佳）、Atsushi Imura。
- 两线共用：技术基建（Maezawa、Jun ITO、Ota Sano、Tachihara、Shinya Goto、Masanori Kanamaru、Ryota Takeuchi、Tomoya Kanehira 在阿尔宙斯、朱紫、零之秘宝、Z-A 四作全勤）、Pokémon 3D Modeling 单元（Ujiie、Nakahiro、Anazawa、Onodera 及约 80 名建模/动作师）、Tomoya Takahashi、Sugimori 的概念设计部、Sound（Ichinose、Hitomi Satō 佐藤仁美）。**GF 的并行不是两个独立工作室，而是"两个企划团队 + 共享的技术部与模型工厂"**，共享部门的人在两条线都署名，所以只看"缺席"会低估共享层的规模。

**Z-A 的形成（2022–2025）分三批**

阿尔宙斯交付（2022-01）后先有跳过朱紫与 DLC 的阿尔宙斯人：Murase（Planning SD → Z-A Plan* Story Team）、Masayuki Jimpo、Ryo Katsura、Yasuhisa Sakamoto、Mizuki Fujita；朱紫交付（2022-11）后加入 DLC 缺席者 Saita、Kawazoe、Makita、Uematsu、Kawakami、Kota Yamashita、Ishige、Morimoto、Nabana；DLC 交付（2023-12）后 Murayama 接 Planning SD，Tochigi 任 Director。Z-A 的 Director（Tochigi）、Story lead（Murase）、Section Director（Yuki Yamamoto）都出自阿尔宙斯，它是阿尔宙斯线的传承作。零之秘宝则由朱紫留守组做，Director Ichiraku + Murayama，Masuda 挂 General Producer，Shinya Saito 新任 Producer。
