你好，我是负责网站工作的カニ子（蟹子）。<br>

从今天起，新增了名为[“GAME FREAK秘密基地”](http://secretbase.gamefreak.co.jp/)的<br>

趣味内容！

GAME FREAK秘密基地是 GAME FREAK<br>

将在网站上公开各种实验性内容的实验场。<br>

作为第一弹实验内容，我们公开了名为[“点阵分享”](http://secretbase.gamefreak.co.jp/dot_share/dot_parts.php)的<br>

博客挂件。

右侧显示的就是点阵分享的实际效果。<br>

现在处于“仅查看模式”，<br>

但平时，前来浏览博客的客人都可以一起点阵绘图，<br>

作为一种能够共同创作图画的小配件来使用。<br>

点阵分享的说明页面上有示例，请去玩玩看吧。

另外，我们还在 GAME FREAK秘密基地的首页<br>

试着加入了“自言自语吐槽功能”。<br>

可以听到 GAME FREAK 员工每天更新的自言自语，<br>

用户们也可以针对这些内容一起吐槽。<br>

有空的时候请来吐槽一下吧。<br>

敲敲门，还可以看到大家的吐槽哦。

以上就是 GAME FREAK 新增趣味内容的消息。<br>

今后 GAME FREAK 网站也会继续进行各种有趣的实验。<br>

敬请期待喽。

<br>

<div data-gf-language-panel="ja" hidden>
こんにちは、Web担当のカニ子です。<br>

今日から[「ゲームフリークひみつきち」](http://secretbase.gamefreak.co.jp/)という<br>

オタノシミコンテンツが新たに追加されました！

ゲームフリークひみつきちは、ゲームフリークが<br>

Webでいろいろな実験コンテンツを公開していく実験場です。<br>

実験コンテンツ第一弾として[「ドットシェアー」](http://secretbase.gamefreak.co.jp/dot_share/dot_parts.php)という<br>

ブログパーツを公開しました。

右側に表示されているのがドットシェアーの現物です。<br>

これは「見るだけモード」になっていますが、<br>

ふだんはブログを見に来たお客さんみんなでドットを打つことができる、<br>

共同でお絵描きできるアクセサリーとして使えます。<br>

ドットシェアー解説ページにサンプルがあるので遊んでみてください。

また、ゲームフリークひみつきちトップページには<br>

「ヒトリゴトツッコミ機能」をつけてみました。<br>

ゲームフリークスタッフの日替わりヒトリゴトが聞けて、<br>

それに対してユーザーみんながツッコミを入れられる機能です。<br>

暇な時にツッコんでみてください。<br>

みんなのツッコミもドアをノックすると見る事ができますよ。

以上、ゲームフリークに加わった新たなオタノシミのお知らせでした。<br>

これからもゲームフリークWebでは楽しい実験をしていきます。<br>

おたのしみにー。
