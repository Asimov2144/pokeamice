- type: heading
  level: 3
  original: 覚悟ができているか
  translation: 是否做好了觉悟
- type: text
  speaker: 渡边哲也
  original: この業界で生きていく覚悟がある人が欲しいです。ものを創作してそれを飯の種にしてこうと思っているかってことですね。この業界はものが完成しなかったり、発売しなかったら０の世界だから、覚悟してないと厳しいと思いますよ。
  role: answer
  translation: 希望有在这个行业生存下去的觉悟的人。就是有没有打算创作东西并以此为生。这个行业，如果东西没完成、没发售，就是零的世界，所以没有觉悟的话会很严峻。
- type: text
  speaker: 渡边哲也
  original: プログラマーに限らず、どの職種においても「創りたい！」っていう熱意、気合いみたいなものが一番大切かな。犠牲を払っても自分の創りたいものを創るという強い意思を持った人がいいですね。そういう人間じゃないといいもの創れないと思います。
  role: answer
  translation: 不限于程序员，无论哪个岗位，我觉得“想创作！”这种热情、干劲是最重要的。最好是那种即使付出牺牲也要创作自己想创作的东西，有强烈意愿的人。我觉得不是这样的人，就创作不出好东西。
- type: text
  speaker: 渡边哲也
  original: もちろんただ「自分の好きなことだけやりたい」というのは困るけど、強引でもいいから資料なんか揃えて周囲を説得できる人が望ましいですね。それができる環境は常に用意しているつもりです。
  role: answer
  translation: 当然，只是“只想做自己喜欢的事”会让人为难，但最好是即使强硬，也能准备好资料说服周围的人。我打算一直准备好能这么做的环境。
- type: heading
  level: 3
  original: 技術が「遊び」を創る
  translation: 技术创造“游玩”
- type: text
  speaker: 渡边哲也
  original: 僕は自分が技術屋だからというのもあるけど、まず技術が先にあった上で新しい発想、新しい「遊び」が生まれると思っています。先にアイデアがあるってパターンもいいとは思うけど、本当に新しいゲームっていうのは新しい技術からしか生まれないんじゃないかなと。例えば新しいＲＰＧはプランナーでも創れるけど、誰も触ったことのないゲームというのは、基盤となる技術がないと生まれないと思うんですよ。
  role: answer
  translation: 我自己是技术出身，所以也有这方面原因，但我认为首先有技术，在此基础上才会产生新的想法、新的“游玩”。先有想法的情况我也觉得不错，但真正新的游戏，我觉得只能从新技术中诞生。例如新的RPG策划也能创作，但谁都没接触过的游戏，我觉得没有基础技术就不会诞生。
- type: text
  speaker: 渡边哲也
  original: だからプログラマーが新しいゲームのベースとなるような仕組みを創る時間をもっと持っていきたいし、そういうことしたいと思っている人がいいですね。全員が自分に関心のある技術を追い求めていけば、当然今ある企画では使えない技術もあって、それが別の１タイトルの礎になれば理想的だと考えています。
  role: answer
  translation: 所以，我希望程序员能有更多时间创造成为新游戏基础的结构，也希望有想这么做的人。如果所有人都追求自己关心的技术，当然也会有现在企划用不上的技术，如果那能成为另一款作品的基石，我认为是理想的。
- type: text
  speaker: 渡边哲也
  original: 現状では、特にこの技術がうちに必要、というものは特に無いですね。始まってからどんな技術が欲しいというのは見えてくるものだと思うので、その人なりのウリになるようなものがあればいいですよ。「この分野なら誰にも負けない、こんなことが出来ますよ」ということをアピールしてくれたらいいと思います。
  role: answer
  translation: 现状是，并没有特别需要这个技术。开始之后，需要什么技术会逐渐看清，所以只要有那个人自己的卖点就好。如果能宣传“这个领域我不会输给任何人，我能做这样的事”就好了。
- type: text
  speaker: 渡边哲也
  original: 高い技術力はあるに越した事はないけど、実績があり、エネルギッシュな人は自分で会社起こしちゃうでしょう。だから「まだ自分で会社創るまではいかないけど、この世界で生きる覚悟が出来ている」という人であればいいです。いずれ独立しようと思っててもいいですよ。もちろん、そこまで言うからには何か会社に落としていって欲しいですね。
  role: answer
  translation: 技术高当然越好，但有实绩、精力充沛的人会自己开公司吧。所以，只要是“虽然还没到自己开公司的程度，但已经做好在这个世界生存的觉悟”的人就好。将来想独立也可以。当然，既然说到这个份上，希望你能给公司留下点什么。
- type: heading
  level: 3
  original: アウトローでもいい
  translation: 做个异类也无妨
- type: text
  speaker: 渡边哲也
  original: アウトローでもいいと思うんですよ。会社でやってけるかどうかは本人次第。何かしら実現したい目標があってきっちり進んでいける人ならアウトローだっていいでしょう。
  role: answer
  translation: 我觉得做个异类也无妨。能不能在公司干下去，全看自己。只要有想实现的目标，能踏踏实实往前走，就算是个异类也没关系。
- type: text
  speaker: 渡边哲也
  original: 遠回りしても全てを受け入れて、その中でどうすべきか考えて自分はこれでいいんだって判断した上で歩いていける人ですね。間違っていてもそれは問題じゃない。自分で結論を出して、だからどんな結果でも自分の責任だって思える人がいい。「どうすべきですか？」なんて質問に答えはないから。
  role: answer
  translation: 哪怕绕远路，也能接受一切，在其中思考该怎么做，自己判断这样就行，然后走下去的人。就算错了也不是问题。能自己得出结论，觉得不管什么结果都是自己负责的人就好。因为“该怎么做？”这种问题没有答案。
- type: text
  speaker: 渡边哲也
  original: ものを創る人間は「俺の作品を見ろ！」ってパワーがあってなんぼだと思うんです。プログラマーはその限りじゃないけど、プランナーとかデザイナーとかそういうパワーを持つ人とわたり合っていかなければならない仕事でしょう。人に引っ張られていくのもいいけど、技術的なバックボーンを持った上で、型破りでもいいから引っ張っていける人が欲しいです。そういう人がどんどん強引に進めていってくれたらいいですね。
  role: answer
  translation: 做东西的人，我觉得有“看我的作品！”这种劲头才够。程序员倒不一定，但策划、设计师这些有这种劲头的人，得能跟他们较劲才行。被人拉着走也行，但希望有技术底子，哪怕不按常理出牌，也能带着大家走的人。这样的人能不断强行推进就好了。
