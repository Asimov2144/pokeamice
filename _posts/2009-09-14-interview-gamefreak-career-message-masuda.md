- type: text
  speaker: 增田顺一
  original: 今回は沖縄のゲームを作ります、という時にサウンドクリエイターが沖縄の音階を使うというのは日本国内では当たり前の手法ですが、海外から見た時にはどう見えるのか？一つの視野ではなく広い視野で世界の人が聴いたらどう感じるのかを考えて欲しいです。ゲーム内の雰囲気は非常に沖縄っぽいけど、あえて沖縄の音階は外す、違う価値観、世界観を構築するにあたって色々視野を持てる、というような感性をゲームフリークでは大事にしています。
  role: answer
  translation: 这次要做冲绳的游戏，这时候声音创作者使用冲绳的音阶，在日本国内是理所当然的手法，但从海外来看会是什么样？不要只用一个视角，而是用更宽的视野去想世界上的人听了会有什么感受。游戏内的氛围非常像冲绳，却特意去掉冲绳的音阶，在构建不同的价值观、世界观时能持有各种视野，GAME FREAK重视这样的感性。
- type: text
  speaker: 增田顺一
  original: CDで聴く音楽とは違いゲーム音楽では決まった型にはまる必要の無い自由さがあります。バンドを組むならベースとギターとドラムとキーボードとボーカル、と固定されてしまっていますが、ゲーム音楽にはそういう常識は関係ありません。新しい世界観を作るのにゲーム制作は優れた環境です。ゲームフリークでは既成概念に捕われずに自由な発想を持った人の活躍できる環境があります。
  role: answer
  translation: 和用CD听的音乐不同，游戏音乐有不必套进固定模式的自由。组乐队的话会被固定成贝斯、吉他、鼓、键盘和主唱，但游戏音乐和这种常识无关。在创造新世界观方面，游戏制作是很好的环境。GAME FREAK有让不被既有概念束缚、拥有自由想法的人发挥的环境。
- type: text
  speaker: 增田顺一
  original: サウンドクリエイターにはピアノが得意であるとか、ギターが得意であるとか売りがある人が多いと思うのですが、楽器に固定されないような挑戦心を持ったサウンドクリエイターが欲しいですね。「4分33秒」という、何も演奏しない無音を楽しむ曲があるのですが、それに匹敵する位のアイディアを持っているとか。既成概念に捕われずに、新しい物を産み出せる。そんな人と仕事がしたいですね。
  role: answer
  translation: 声音创作者里，我想很多人有擅长钢琴、擅长吉他之类的卖点，但我们想要的是不被乐器固定住、有挑战心的声音创作者。有一首叫《4分33秒》的曲子，什么都不演奏，享受无声，希望你有能和它匹敌的点子。不被既有概念束缚，能创造出新东西。我想和这样的人一起工作。
- type: heading
  level: 3
  original: 明るくて元気な人
  translation: 开朗有活力的人
- type: text
  speaker: 增田顺一
  original: テレビゲームの音楽はこうである、というコダワリは重要視していますが、それ以上にゲームだからこそできる事をやってみたいという想いを今回の求人では受け入れていきます。サービス精神を持った人などよいですね。自分の主張を持っていてもいいけれど、ゲームをプレイするプレイヤーに何がマッチするかを考えた上で主張する。サービス精神を旺盛に持って自分から率先して提案したり作ったりして欲しいです。ゲームフリークでは分業体制を取っておらず、異業種間で協力して作っていく体制になっています。受け身になって「グラフィックができていないから曲を作れない」ではなく、共有されたイメージから曲を一緒に作っていける人を求めています。分業しないという環境は非効率的な体制かもしれないですが、この体制だからこそ、他には無いより良いものを作れるのではないかと考えています。絵が無ければ音は作れない、というような人はうちには向いてないでしょう。こんな世界にはこういうのがいいんじゃないか、と自分から世界観を説明していける人がいいですね。そういう意味でも「明るくて元気な人」が嬉しいです。
  role: answer
  translation: 电视游戏音乐应该是这样，这种讲究我们很重视，但这次招聘更愿意接纳想做只有游戏才能做到的事的想法。有服务精神的人就很好。有自己的主张也可以，但要在想过什么才适合玩游戏的玩家之后再主张。希望你有旺盛的服务精神，自己主动提议、主动制作。GAME FREAK不采用分工体制，而是不同职能之间协作制作的体制。我们需要的不是被动地觉得“画面还没做好所以做不了曲子”，而是能根据共享的印象一起做曲子的人。不分工的环境也许是效率不高的体制，但正因为这个体制，才能做出别人没有的更好的东西吧。觉得没有画面就做不了音乐的人，大概不适合我们。能自己说明“这样的世界这样不是很好吗”的人就好。从这个意义上说，“开朗有活力的人”让人高兴。
- type: heading
  level: 3
  original: 音フリークである
  translation: 是声音狂热者
- type: text
  speaker: 增田顺一
  original: 音そのものに関心が高い、というのがサウンドクリエイターに大事な事ではないかと思っています。たとえば映画マトリックスの主人公が会社で叱られるシーンで窓ガラスを清掃してる音が異常に大きく聞こえるんですが、主人公に対しての厳しいセリフと窓ガラスの音でバツグンに嫌な気持ちになる雰囲気が演出されていると僕は感じました。そういう音の演出に関心が持てる人。音自体が面白いと思っている人にゲームフリークに来て欲しいです。
  role: answer
  translation: 对声音本身有高度关心，我想这对声音创作者来说是很重要的。比如电影《黑客帝国》里主角在公司被骂的场景，打扫窗玻璃的声音听起来异常大，我感觉严厉的台词和窗玻璃的声音一起，营造出了极其让人不舒服的氛围。能对这样的声音演出感兴趣的人。希望觉得声音本身有趣的人来GAME FREAK。
