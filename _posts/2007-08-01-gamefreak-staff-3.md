<div data-gf-language-panel="zh-CN">
初次见面。我是 GAME FREAK 的工作人员カニ子（蟹子）。<br>

我入职 GAME FREAK，负责网站制作。<br>

今后还请多多关照。

这次，正值 GAME FREAK 网站全面更新，<br>

作为趣味内容的一环，我们从今天开始写员工博客。<br>

关于 GAME FREAK 里那些有点奇怪却很有趣的快乐日常，<br>

我想想到什么就写写，没写也就没写吧。

那么，在这次更新中，我们给首页做了一个有趣的小机关。<br>

这是一个点击后颜色会逐渐变深的点阵画布。

可以通过点击加深的颜色只有 3 个层次，虽然不算多，<br>

但这是因为我想起了 Game Boy 的颜色深浅曾经只有 3 个层级，于是就做成了这样。<br>

GAME FREAK 的《宝可梦 红·绿》也是 Game Boy 上的作品。<br>

当时仅凭 3 个层级的深浅，就表现出了那样丰富的角色。<br>

只有 3 个层级，却又不仅仅是 3 个层级。点阵图中蕴藏着无限的可能性。

也请你亲自点击点阵，试着表现出各种各样的效果吧。<br>

那么下周再见啦！

<br>
</div>

<div data-gf-language-panel="ja" hidden>
はじめまして。ゲームフリークスタッフのカニ子と申します。<br>

ゲームフリークにWeb制作担当として入社しました。<br>

これからよろしくお願いいたします。

このたび、ゲームフリークWeb全面リニューアルをきっかけに<br>

オタノシミコンテンツの一環として本日よりスタッフブログを始めました。<br>

ちょっとヘンだけどおもしろいゲームフリークでの楽しい日々を<br>

書いたり書かなかったりしていこうと思います。

さてさて、今回のリニューアルではトップページに楽しい仕掛けをつくりました。<br>

クリックすると色の濃くなるドット絵キャンバスです。

クリックして濃くできる色は3段階と少ないですが、<br>

これはゲームボーイの色の濃さが3階調だったことを思い出してつくったものです。<br>

ゲームフリークの「ポケットモンスター 赤・緑」もゲームボーイの作品。<br>

たった3階調であんなにも豊かなキャラクター達を表現したのです。<br>

たった3階調、されど3階調。ドットには無限の可能性が秘められています。

ぜひあなたもドットをクリックして色々な表現をしてみてください。<br>

それではまた来週！

<br>
</div>
