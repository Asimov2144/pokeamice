- original: What has it been like moving into fully 3D environments when you've spent so long making the core series in a top-down viewpoint?
  role: question
  speaker: Nintendo Life
  translation: これまでずっと見下ろし視点で本編を作ってきた中で、完全な3D環境に移行するのは、どのような経験でしたか？
- original: This time with the move to full 3D you can freely manipulate the camera angles, which you couldn’t do before. Being able to move cameras around freely and frame the scene just how we wanted added a lot of new possibilities, but at the same time a few challenges. It was difficult trying to get that right. For example, we can show scenes from any angle, but due to hardware limitations we can’t show things that are really far away, the rendering power isn’t quite there so there’s a drop in performance. Because of this we had to find ways around this, for example if we wanted to show a town from far away we can do that camera angle but we have to maybe use a lower polygon model for the background.
