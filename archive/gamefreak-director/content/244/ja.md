ついに『Pokémon GO』を発表することができました。

{% spacer %}

マスダのツイッターに世界中から、

「とても楽しみ！ワクワクする！」

「すぐに冒険にでかけたい！」

「子どもの頃の夢が現実になった」

などなど、、、

たくさんの嬉しい言葉を頂きました。

{% spacer %}

応援されることは何よりもパワーになります。

ものをつくる人間として、これ以上心強いものはありません。

幸せです。

みなさん、本当にありがとうございます！

{% spacer %}

『Pokémon GO』では世界観の構築、ゲームデザイン、音楽で参加していますが、

ポケモンの世界観やゲームデザインの常識を取り払い、分解し、新しいデザインによって、

位置情報ゲームとして楽しめるものにしています。

{% spacer %}

開発はまだまだ続きますが、

世界中のみなさんに楽しんでもらえるよう、

Nianticと共に最高のものづくりをしていきます。

{% spacer %}

世界中のポケモンファン、世界中のIngressファン、そしてポケモンを遊んだことがない人にも。

みんなに楽しんでもらえるものづくりをしっかりしていきたいと思います。

{% spacer %}

ポケモン２０周年に向けて、みんなへの感謝の気持ちを込めて。

{% spacer %}

２０１６年スマートフォン（iOS、Android）でリリース予定です。

どうぞ、ご期待ください！
