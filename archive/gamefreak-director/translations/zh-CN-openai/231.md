大家好！

昨天，也就是２０１２年１２月１６日（星期日），动画店秋叶原店举办了签名会活动！

真的非常感谢大家前来参加！！

这次，我想一边向大家表达谢意，一边带大家看看活动当天的情况。

{% image id="231-multi-121217_01" %}

活动当天，一大早店门前就排起了长队！！

之前还担心到底能有多少人来参加，没想到现场热闹得让我又惊又喜！

其中甚至有人从凌晨４点就开始排队了！！！

这么冷的天还要等这么久，真的辛苦大家了。

{% image id="231-multi-121217_02" %}

原本计划在11：00-和14：00-举办两场，

但因为报名人数达到了上限，没想到临时决定再加开第三场！！

即便如此，还是有一些朋友没能参加，真的很抱歉。请一定期待下一次机会！

然后，１１点整。

活动终于开始了！

我以最近加入的等离子队成员身份登场！！

“宝可梦早安！！”“等离子队！！”

{% image id="231-multi-121217_03" %}

GAME FREAK 开发的最新软件《[节奏猎人 和谐骑士](https://www.gamefreak.co.jp/harmoknight/index.html)》开发团队也一同参加了活动。

我们回答了大家事先通过推特提交的、关于宝可梦和和谐骑士的问题！

{% image id="231-multi-121217_04" %}

接着，签名会开始了！

大家如果仔细看看照片，或许就能发现，

这次签名会用的签名板是特别规格。没想到……！！

{% image id="231-multi-121217_05" %}

这是宝可梦与和谐骑士的联动插画签名板！

{% image id="231-multi-121217_06" %}

负责和谐骑士的导演和角色设计，

同时也负责宝可梦角色设计的詹姆斯，

专门为这次活动绘制了这幅画！

然后是惯例！？的集体合影时间！！

和到场的约180位朋友全员合影留念！
