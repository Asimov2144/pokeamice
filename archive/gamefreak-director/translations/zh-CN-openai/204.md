顺利抵达圣迭戈的酒店了！

在成田听到雷声轰鸣、收到飞机延误的通知时，

我还兴致勃勃地想着：一定要把闪电拍下来！

感觉就像在玩音乐游戏一样，我看准时机，

根据上一次闪光的位置、间隔和声音，瞄准按下快门的机会，

结果就像大家看到的这样，拍得相当漂亮！成功把它的身影拍了下来！

{% image id="204-multi-204a" %}

然后比预定时间晚了大约１小时抵达洛杉矶。

在洛杉矶，光是入境审查就等了好久……

而且还花了１个多小时……

从洛杉矶到圣迭戈的巴士也遇上了堵车……

{% image id="204-multi-204b" %}

照片里是对向车道。

那么，单侧到底有几条车道呢？（笑）

这么宽的路居然还会堵车……

最后比原定计划晚了３个小时抵达酒店！

一场从雷声开始的旅程。哎，不过这趟旅途还真够漫长的……

酒店里已经准备就绪了。

{% image id="204-multi-204c" %}

看着远处捷克罗姆前面的那两个人，就能明白这里有多宽敞了吧。

完成彩排、吃过饭之后……回到酒店……

偷偷地，溜进会场里面……

{% image id="204-multi-204d" %}

世界锦标赛将于当地时间１３日开幕。

我们静静地等待着那一刻。

用各个国家的语言写着“欢迎光临！”

{% image id="204-multi-204e" %}

感觉非常棒。

{% image id="204-multi-204f" %}

外面已经彻底进入深夜了……

我在海湾前线为大家发来报道！

那么，晚安！！
