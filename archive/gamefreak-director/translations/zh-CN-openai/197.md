6月6日（周一），我乘坐了从东京出发的N’EX！

{% image id="197-ja-197a" %}

这个车头，近距离看更能感受到它的力量感，对吧。

{% image id="197-ja-197b" %}

真帅……

啊，说起来，我为什么要乘坐N’EX呢……

没错，我要去洛杉矶参加在那里举办的E3！

首先，从东京乘坐N’EX到成田，大约需要1小时。

再从成田机场搭乘傍晚起飞的飞机，飞行时间大约10小时。

日本和洛杉矶有16小时（夏令时）的时差……

抵达时是6日（周一）上午11点。

又重新过了一遍6号（笑）

走出机场，眼前就是洛杉矶！

空气、湿度、气味，全都完全不同！！

然后，我们坐出租车前往酒店！

（这张照片是我在出租车上，朝洛杉矶机场方向抓拍的（笑））

{% image id="197-ja-197c" %}

路好宽！而且还免费！！

（不过路面坑坑洼洼的！这里也不下雨，难道不太花钱维修吗？）

{% image id="197-ja-197d" %}

终于到了酒店！总算到了！

从我房间的窗户看出去！

{% image id="197-ja-197e" %}

虽然困得不行……还是努力去了圣莫尼卡！

{% image id="197-ja-197f" %}

是大海——！！

{% image id="197-ja-197g" %}

是大海——！！海也宽广，天空也宽广！！

{% image id="197-ja-197h" %}

圣莫尼卡的游乐园！摩天轮转得特别快！

{% image id="197-ja-197i" %}

那里还有游戏厅呢！

摆放的游戏大多是狩猎题材的！！

（摆放的街机和日本有所不同，难道这就是狩猎民族与农耕民族的差别吗？）

第一天接下来，我们去了海鲜餐厅。

肚子一填饱……那叫一个困啊……

就算像这样简单地比较一下日本和洛杉矶，

也会发现两边完全不一样，对吧。

虽然可以在网上查各种资料、浏览各种图片，

但果然，能够实际来到当地，调动听觉、视觉、味觉、触觉和嗅觉这五种感官，

去感受当地的空气，或许就是只有亲自来过的人才能享有的特权。

请大家也一定要趁年轻多去旅行！！

再会！
