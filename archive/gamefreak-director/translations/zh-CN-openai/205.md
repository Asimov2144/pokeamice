13日，开幕式当天。

早上7点，会场里已经开始彩排了。

视频游戏开始！

这期间，我又是彩排，又是正式活动，

又要参加签名会，还要在颁奖仪式上登台……

结果一张自己的照片都没有（笑）

然后是闭幕式。

刚从台上下来，就立刻喊着：照片！照片！（汗）

{% image id="205-multi-205g" %}

{% image id="205-multi-205h" %}

大家，谢谢你们前来参加！

还有，世界冠军！恭喜你们！！

大家都打出了精彩的比赛！

还有获得第二名的选手，也辛苦了！！

大家真的非常感谢！！

{% image id="205-multi-205i" %}

哎呀，今年的圣迭戈也太厉害了！

现场气氛真是太热烈了！

每次看到这样的活动，我都会想起一件事。

如果只在公司里制作游戏，就看不到玩家们的表情，对吧。

这就像艺术家只制作网络内容或唱片，却不举办展览或现场演出一样。

那样的话，果然还是会觉得缺了点什么。

看不到客人的表情，也看不到他们会对什么产生反应。

也许有人会觉得，看不到也没关系，

但那就和在餐厅里不考虑客人的感受，

只做老板自己喜欢的东西一样。只是自我满足。

这样当然不可能让许多客人满意。

就这样在现场和玩家接触，

看着大家游玩，再去思考未来，

我们会获得非常非常多的能量。

也会由此产生想要创作出更好作品的心情。

正当我一边感受着这些，一边重新振作起精神时……

圣迭戈的夜晚将我们温柔地包裹其中。

{% image id="205-multi-205j" %}

{% image id="205-multi-205k" %}

第二天。自由活动！

于是，我们首先去了……

中途岛号博物馆。

{% image id="205-multi-205l" %}

把军舰原封不动地变成博物馆……这个想法真是太厉害了……

还可以通过耳机收听日语导览。

{% image id="205-multi-205m" %}

{% image id="205-multi-205n" %}

门的构造也很厉害。是为了绝对不让敌人进来吗？？

{% image id="205-multi-205o" %}

午餐是……我最喜欢的螃蟹！！乔氏螃蟹店真好吃！

{% image id="205-multi-205p" %}

然后，又去了每次都会去的海洋世界。

{% image id="205-multi-205q" %}

{% image id="205-multi-205r" %}

虎鲸，好大啊！！和人一对比，就能感受到它的体型了吧。

{% image id="205-multi-205s" %}

这里的虎鲸昵称叫作“沙木”。

大家一起高喊“沙木”！

然后，竟然还！！

去现场看大联盟比赛！！

在佩科公园球场观看教士队对大都会队的比赛！！

{% image id="205-multi-205t" %}

作为一场对决来说，就是圣迭戈对纽约！！

既然如此，当然要为教士队加油啦！

这里是三垒大都会队一侧。我们的座位就在这里，不过马上就换地方了！

{% image id="205-multi-205u" %}

从一垒教士队一侧的外野观看比赛！！加油啊！教士队！！

最远的地方还有草坪和巨大的屏幕！

这样一来，就能像在家里一样舒舒服服地看比赛了。

{% image id="205-multi-205v" %}

教士队对大都会队的比赛，就这样热热闹闹地进行着。

一开始大都会队先拿下3分，我还想着“咦咦？”，

没想到中途奋起直追，比分变成了4比4。

虽然大家都在为他们加油，可最后还是在延长赛中输掉了。

教士队……

哎呀，真是比我预想的有趣多了。

有意思的地方包括……

没有铁丝网！球会飞到很近的地方。（受伤了要自己负责？）

打出界外球时，还能拿到球。

不是用音乐带动助威，而是靠观众自己的声音来加油。

欢呼声特别大！人浪也非常壮观！

有些事情，不亲自去一趟就不会明白，

真的有非常非常多。

就这样，我们尽情享受了精彩的世界锦标赛和圣迭戈，

然后回到了日本！
