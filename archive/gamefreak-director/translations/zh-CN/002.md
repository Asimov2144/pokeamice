GAME FREAK 在创作游戏的时候，

会避免被「因为是电视游戏」「因为是计算机」这样的框架或固定观念所束缚。

那是因为，计算机程序本身就是虚拟、空想的世界。

现实中不存在的事情，也能随心所欲地实现。

要把这种无所不能的空想讲给别人听时，

举出现实中真实存在的例子，就会变得非常容易理解。

现实的东西，对于空想来说，是必要的。

{% spacer %}

比如说，

试着说明一下竹蜻蜓。

「装在头上，像直升机一样飞行的机器」

这样说，就很容易懂。

当然，名字也是由此而来，所以更加容易理解。

记忆面包也是一样。

{% spacer %}

拿宝可梦来说，

不是直接搬运宝可梦，而是放进精灵球里搬运。

从计算机程序的角度来想，其实没必要特意装进球里。

但是，在那里加上一点巧思，就能带来现实感。

如果因为「因为是计算机」就草率了事，那就太过于空想，反而无法传达。

{% spacer %}

我一直在思考的是，

「赋予现实的理由，让空想更加真实」

{% spacer %}

把困难的事情，用现实而简单的方式呈现出来。

这样一来，人们就会更容易接受吧。

{% spacer %}

而在宝可梦中，这样的用心，在非常多的地方都被细致地融入其中。

{% spacer %}

对于初次接触游戏，或者平时不玩游戏的一般人来说，

容易理解、容易操作、感觉舒适——

这正是增田所追求的游戏设计的基础。

{% spacer %}

让一般人也能轻松接受的结构。

思考这些，也很有趣哦。

{% spacer %}

那么，再见！
