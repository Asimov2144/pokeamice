１２周年纪念企划第二弹！

「宝可梦 皮卡丘版」

像动画中的皮卡丘一样，皮卡丘会发出“皮卡丘”的叫声。

因为Game Boy没有高性能的采样功能，

所以必须想办法让它发出“皮卡丘”的声音。

于是，当时也是程序员的增田，

制作了一个将声音转换为1比特数据的转换器，

并编写了播放它的程序。

原理是这样的：

首先，用采样器等设备将声音数字化。

{% image id="126-ja-pt0229_01_s" %}

※这个波形是帝牙卢卡的叫声。波形看起来就是这样。

放大后，是这样的。

{% image id="126-ja-pt0229_02_s" %}

再放大，

{% image id="126-ja-pt0229_03_s" %}

几乎变成数字状态。波形作为音量数据被数值化。

用转换器把它变成0和1。

数据看起来像这样……

{% image id="126-ja-pt0229_04_s" %}

（图片中的红色0和1）

哪个级别设为1也会影响声音，所以转换器准备了多种转换方式。

这些0和1通过Game Boy的点击噪音（噼啪声）来播放，

0不发声，1发声，这样高速进行。

高速进行是关键。

越快音质越好。

“皮卡丘”完成了。
