12周年纪念音乐企划！

我想一边比较过去的开场曲，一边看看至今为止音乐的变化。

※只播放曲子的一部分。另外，包含演出效果音。敬请谅解。

（1）宝可梦 红·绿·青

开场演示

{% spacer %}

标题

{% spacer %}

这是用Game Boy这个游戏机，

音数总共4音。编成是2音矩形波、1音三角波、1音噪声。

作曲是我，增田。游戏内的音乐、效果音和叫声也全部由我负责。

开场曲是从战斗的印象构思的。

然后，标题曲是以怪兽为印象。

最初，先做了30首左右15秒左右的曲子，确认方向性。

之后，制作了整体。

为了营造厚重感，加入了稍微重一点的噪声音，像进行曲一样。

通过一点点改变噪声的音量，表现出小军鼓的跳跃感。

（1）宝可梦 皮卡丘版

开场演示

{% spacer %}

顽皮、淘气、可爱、生气、坦率、蓬松、电、红脸颊，等等……

以从皮卡丘感受到的印象作曲。

由于画面场景切换时会发生大量数据传输，所以下功夫让音乐不会变慢。

（2）宝可梦 金·银

开场演示

{% spacer %}

标题

{% spacer %}

这也是Game Boy。

虽然我作了开场演示的曲，但由我们公司的音效设计师一之濑君进行了编曲。

开头的“咚——咚——”的声音，是以一切开始的钟声为印象。

标题的编曲由增田负责。

顺便说一下，游戏内的音乐是和一之濑君一起做的。

（3）宝可梦 水晶

开场演示

{% spacer %}

标题

{% spacer %}

这是Game Boy Color专用软件。

左右摇动声像等，做了一些实验性的事情。

开场演示和标题由增田作曲、编曲。

从这个时候开始正式成为总监，作曲急剧减少。

（4）宝可梦 红宝石·蓝宝石·绿宝石

开场演示

{% spacer %}

标题

{% spacer %}

从这里开始是Game Boy Advance。

4音采样波形、3音矩形波、1音噪声。

（即使这样，效果音一响，BGM的声音就会被消掉）

这个标题音乐的冲击力很厉害。

一之濑君的编曲。哎呀，太棒了！精彩！

增田只作曲了战斗音乐。

（5）宝可梦 火红·叶绿

开场演示

{% spacer %}

标题

{% spacer %}

Game Boy Advance。

全部是一之濑君的编曲。

商量后，基本音保持原样。决定用追加音来编曲的方向。

（6）宝可梦 钻石·珍珠

标题

{% spacer %}

从这里开始是DS。

变得能发出任何声音了。

采样、16音这种豪华的规格。（但是，考虑到效果音，用10音制作）

开场的演示和标题曲合为一体，变得超豪华。

这里也闪耀着一之濑君的编曲。

你们明白吗？

这是红·绿标题曲的编曲。

几乎算是原创。厉害！

游戏内的音乐由一之濑君、佐藤小姐、增田负责，

我只负责战斗音乐。

效果音是野原君。

音响工作人员增加了很多。

佐藤小姐和野原君加入后，声音的幅度进一步扩大了！

大家觉得怎么样？

从开场演示、标题音乐看到的宝可梦历史。

既令人怀念又新鲜，让人回想起当时。

这也是“音乐的力量”之一呢。
