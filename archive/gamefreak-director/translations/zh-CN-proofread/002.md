在GAME FREAK创作游戏的时候，

我们尽量不持有「因为是TV游戏」「因为是电脑」这样的框架或固定观念。

那是因为，电脑程序本身就是虚拟、空想的世界。

现实中不存在的事情，也能做到一切。

当向他人讲述这种无所不能的空想时，

举出现实中的真实例子会变得非常容易理解。

现实的东西对空想来说变得必要。

{% spacer %}

例如，

试着说明竹蜻蜓。

「装在头上，像直升机一样飞行的机器」

这样说，就容易理解。

当然，名称也来源于此，所以更加容易理解。

记忆面包也是一样。

{% spacer %}

以宝可梦为例，

不是直接搬运宝可梦，而是放入精灵球中搬运。

从电脑程序的角度考虑，其实不必特意放入球中。

但通过加入这一点巧思，赋予了现实感。

如果因为「因为是电脑」就草率了事，就会过于空想而无法传达。

{% spacer %}

我一直在思考的是，

「赋予现实的理由，让空想更加真实」

{% spacer %}

将困难的事情以现实的方式简单化，并呈现出来。

这样一来，人们就更容易接受。

{% spacer %}

而在宝可梦中，这样的细节被精心地、大量地融入各处。

{% spacer %}

对于初次接触游戏，或者不玩游戏的一般人来说，

容易理解、容易操作、感觉舒适——

这正是增田所追求的游戏设计的基础。

{% spacer %}

让一般人也容易接受的构造。

思考这些也很有趣哦。

{% spacer %}

那么！
