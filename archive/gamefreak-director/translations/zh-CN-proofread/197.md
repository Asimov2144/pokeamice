６月６日（周一），我乘坐了从东京出发的N'EX！

{% image id="197-ja-197a" %}

这个表情。特写的话，更能传达出力量感吧。

{% image id="197-ja-197b" %}

好帅啊。。。

啊，，对了，为什么坐N'EX呢，，，

没错，是去参加在洛杉矶举办的E3！

首先，从东京坐N'EX到成田大约1小时。

从成田机场坐傍晚的飞机，大约10小时的飞行。

日本和LA有16小时（夏令时）的时差，，，

到达时是6日（周一）早上11点。

重新过一遍6日（笑）

出了机场就是LA！

空气、湿度、气味完全不同！！

然后，坐出租车去酒店！

（照片是从出租车拍向洛杉矶机场方向，增田抓拍的（笑））

{% image id="197-ja-197c" %}

道路很宽！而且免费！！

（但是路坑坑洼洼！也不下雨，是不想花钱修吗？）

{% image id="197-ja-197d" %}

终于到酒店了！终于到了！

从增田房间的窗户！

{% image id="197-ja-197e" %}

虽然很困，，，但还是努力去圣莫尼卡！

{% image id="197-ja-197f" %}

是大海—！！

{% image id="197-ja-197g" %}

是大海—！！！海和天空都很广阔！！

{% image id="197-ja-197h" %}

圣莫尼卡的游乐园！摩天轮转得好快！

{% image id="197-ja-197i" %}

也有游戏中心哦！

摆放的游戏大多是狩猎类的！！

（日本和这里摆放的机台差异，是不是狩猎民族和农耕民族的差异呢。）

第一天之后，去了海鲜餐厅。

肚子一饱，，，就困得不行。。。

就这样，仅仅简单比较日本和LA，

就完全不同呢。

虽然可以通过网络查各种资料、看图片，

但果然还是用听觉、视觉、味觉、触觉、嗅觉这五种感官去感受当地的气息，

这或许是只有真正去过的人才能享有的特权吧。

请大家也趁着年轻多去旅行吧！！
