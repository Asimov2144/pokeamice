こんにちは！

Web開発のカニ子です。

先日日食が起こっていたらしいです。

私の席は窓に背を向けているので気が付かなかったのですが、

ゲームフリークのスタッフは見たのか？

というのを聞いてまわってみました。

{% legacy_image id="gamefreak-staff-652d88b0431f" alt="ラッペン" %}

楽しみにしていて、日食グラスを２コも用意していたのに、見逃しました…。

しかも曇り空だから諦めて仕事をしていたら、

会社でも一瞬見えたと聞いて日食ショックはさらに倍増。

次の機会は2035年ということなので頑張りたいです！（ラッペン）

{% legacy_image id="gamefreak-staff-ea404dfa203c" alt="ほず" %}

皆既日食と言っても「少し曇った時」くらいの

暗さかと思っていたのですが、

テレビを見てびっくりしました。

・・・ま、真っ暗じゃないですか！

日食を見ながら、月見うどんが食べたかったです。（ほず）

{% legacy_image id="gamefreak-staff-c591faa12582" alt="デコ" %}

忘れてました。次の２６年後はちゃんと見ます！（デコ）

{% legacy_image id="gamefreak-staff-58822b653fb3" alt="ユッフィー" %}

体調をくずして会社を休み、家で爆睡していました！

日食は気付いたら終わっていて、

キャベツと煮込んだ袋ラーメンを食べつつ、

芸能人の語る日食をテレビで見てました。

サボってたわけじゃないよ！

みなさんも体調の変化（エアコンとか）には注意！（ユッフィー）

{% legacy_image id="gamefreak-staff-b99a7f7698a5" alt="ボーダー丸" %}

世界の日食を夜テレビで観ました。

もし近い将来、太陽の存在が消えてしまったら、

地球人はどうなってしまうのだろうか…。

そんな普段思わないことを考えながら、

自分が自分の力だけで生きているのでは

ないということを感じた日でした。

でも、未来に誰かが太陽も作ってしまうかも！？

（ボーダー丸）

{% legacy_image id="gamefreak-staff-9899debf1065" alt="っやっや" %}

日食の日、生憎のくもり空なので、見れないと信じきっていました。

お茶を買いにキャロットタワー下に降りたら…

写真のような人々が…

{% legacy_image id="gamefreak-staff-9b96ef00f2c3" alt="集まる人々" %}

なんの騒ぎだろう？

{% legacy_image id="gamefreak-staff-352f00659e22" alt="空を見上げる人々" %}

きっと、お台場の等身大ガンダムが三茶に歩いて来たに違いない！

と思いきや、空を見上げたら三日月の様な影が雲に映し出されていました。

『おぉ、日食！』思わず声をあげました。

生憎、携帯電話のカメラしかなく撮影を試みたのですが…

{% legacy_image id="gamefreak-staff-998fe40904b5" alt="日食" %}

光ってしまって三日月に見えません…

肉眼ではどんな風に太陽が見えたのか

日食を甘食で表現してみました。
