こんにちは、Web開発のカニ子です。<br>

休み明け恒例企画。「みんな休み中何してましたか？」を<br>

ゲームフリークスタッフのみんなに聞いてみました。

{% legacy_image id="gamefreak-staff-652d88b0431f" alt="ラッペン" %}<br>

ＤＳの推理系アドベンチャーゲームを３本くらいクリアしました。<br>

おかげで日常生活でも「ここに指紋がついて…」「これを食べると消化は１時間後…」<br>

などと考えるようになりました。（ラッペン）

{% legacy_image id="gamefreak-staff-57ddcfb7c8a9" alt="ジョニー" %}<br>

ジョニーは大晦日に年越し鍋パーティをしました。<br>

周りの一人暮らしをしている女の子達を呼んで<br>

コタツに入って紅白見ながら大盛り上がり（＾＾<br>

紅白終ってからはお互いの抱負を語りました。<br>

楽しかったので今年年末も検討中！（ジョニー）

{% legacy_image id="gamefreak-staff-707010161046" alt="おにいさん" %}<br>

沖縄で南国気分を味わってました?。<br>

やっぱり冬でも温かく、日中は立ち止まっているとジトっと汗が出て来る程。<br>

時期的にはオフシーズンなので、さすがに泳いでいる人はいませんでしたが、<br>

海が綺麗なので浜には観光客がパラパラと。<br>

最後日にはずっと行きたかった『美ら海水族館』で<br>

ジンベイザメのあまりの大きさに圧倒されて帰ってきました！！（ホントにでかいよ）<br>

（おにいさん）

{% legacy_image id="gamefreak-staff-228248e61477" alt="エノキ" %}<br>

実家に帰ったら飼い始めた子犬が居て<br>

なんかおもしろそうな遊び相手キターーーーって飛びつかれました。<br>

ポンポンつきの長めのニットセーター着ていたので<br>

全身で犬のおもちゃにされました。（エノキ）

{% legacy_image id="gamefreak-staff-a7943436e41d" alt="もりもと" %}<br>

サッカー観戦と初詣とセールと新年会。<br>

あとは、お節を作りました。<br>

紫いもで紫色の栗きんとんができたよ！（もりもと）

{% legacy_image id="gamefreak-staff-4319e92832f6" alt="いわし" %}<br>

冬休み中は病気がちで、基本的には帰省して自宅にこもりきりだったのですが、<br>

初日の出だけはどうしても見に行っておきたい！ということで、同じく帰省していた友人たちと<br>

高台にある灯台に登りました！曇っておりなかなかお顔を見せてくれない太陽でしたが、<br>

山手線ゲームで暇を潰すこと30分、日の出時刻はだいぶ過ぎていましたが、<br>

埋め合わせと言わんばかりの満点の輝きを見せてくれました。<br>

1月1日に見に行くだけでこんなにもプレミアムなんだなぁと感心しました。（いわし）

{% legacy_image id="gamefreak-staff-470ddfd96dd9" alt="なぎー" %}<br>

年末年始は実家へ帰省し、外出せずに過ごしました。<br>

大量にDVDを借りてきて、以下の永久ループです。<br>

「DSをしつつプログラムの勉強をする→DSをしつつDVDを見る→DSをしつつプログラムの…」<br>

多分DSもプログラムもDVDも頭に入っていません。<br>

こんな大人になっちゃいけませんよ！(なぎー）

{% legacy_image id="gamefreak-staff-c505828e65e1" alt="おせんべい" %}<br>

冬休みは、去年もやった２日間スキーに乗り続けるチャレンジをしました。<br>

今年も2日間スキーに乗り続けることに成功しました。<br>

でも今年は、右足がしびれる謎の病気にかかってしまいました。（おせんべい）

{% legacy_image id="gamefreak-staff-3220fb3479df" alt="スティック" %}<br>

ずっと実家に帰ってました。<br>

親にデジタルフォトフレームを買ってあげてデジカメで<br>

撮り溜めた写真を入れて置いたんですが親が２時間モニターを<br>

眺めたまま動かなくなりました。いい贈り物した！<br>

あとは田舎っぽく正月顔合わせを親戚同士でしたところ<br>

おばあちゃんは今年で９０歳！ひ孫は１５人!<br>

血が脈々と受け継がれていっているのを感じるお正月でした。（スティック）

{% legacy_image id="gamefreak-staff-d03ced8cc346" alt="さとう" %}<br>

勇気をだして視力矯正手術にチャレンジしました！<br>

…怖かったです。が、すごくよく見えます。<br>

メガネもコンタクトレンズもいらない生活にまだちょっと慣れません。（さとう）

{% legacy_image id="gamefreak-staff-07b3a5396fa1" alt="ヒロ" %}<br>

久々に、押入れから天体望遠鏡を引っ張り出して、<br>

星を見ました！<br>

寒い夜に、月やオリオン座を見るのは<br>

なかなか風情がありました?。（ヒロ）

{% legacy_image id="gamefreak-staff-58822b653fb3" alt="ユッフィー" %}<br>

バーゲン開始のアウトレットモールであれこれ買い込み、帰りにゲームセンターへ。<br>

メダルゲームに三時間も夢中になって、<br>

メダルの貯金は増えたものの、終電をなくしてタクシー帰宅となり、<br>

実際のお金は消えていきました。<br>

次の日は厄払いのお札をいただきに近所の不動尊へと向かいましたが、<br>

途中でやっぱりバーゲンに行きたくなり、お金だけ払って退出。<br>

お札はまだ取りに行っていません。<br>

わたしのお正月はいつ来るのでしょうか？（ユッフィー）

カニ子はというと1日16時間くらい寝てました。<br>

あと無人島に漂流する海外ドラマのシーズン３を見続けて、<br>

もしも無人島に漂流したらどうしようとか考えてました。

冬休み最終日はずっと休みが続けばいいのに！<br>

いっそ無人島に漂流したい！ とか思ったりしましたが、<br>

仕事が始まって外に出てみると会社楽しいなぁ…！ と感じられて良かったです。<br>

寝貯めもしたし、今年もがんばります！
