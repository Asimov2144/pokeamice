大家好，我是カニ子（蟹子）。<br>

上周暂停更新的员工日志，<br>

是因为 GAME FREAK 进入了暑期休假。

按照大型连休后的一贯惯例，<br>

我们来问问 GAME FREAK 的员工们：“暑假都做了些什么？”

{% legacy_image id="gamefreak-staff-707010161046" alt="おにいさん" %}<br>

今年有幸当上了父亲，所以这个夏天一直和出生才4个半月的儿子，<br>

从早安到晚安都黏在一起，悠闲又慵懒地度过。<br>

他现在还只会说“呜——”或者“哒啊啊”，有时还会毫无预兆地放声大哭，<br>

让大人们手足无措，不过每当他一动不动地凝视着我，那双纯真的眼睛就让我彻底投降了！<br>

总之，这是一个彻头彻尾的笨蛋家长式暑假——！（おにいさん（哥哥））

{% legacy_image id="gamefreak-staff-a55742a47d80" alt="マシュー" %}<br>

总之就是玩了个痛快……！<br>

逛美术馆、去游乐园、和朋友见面、画画、看电影！<br>

我发现一个星期里原来能做这么多事情！真是又惊讶又感慨。<br>

今后也想比平时更加珍惜每一天，好好度过。（マシュー（马修））

{% legacy_image id="gamefreak-staff-310b7f660695" alt="しゃち" %}<br>

为了帮忙，我久违地去了趟静冈县祖父家。<br>

发现屋檐下长着4个马蜂窝！于是拿一罐杀虫喷雾和一张捕虫网当武器，开始捕猎。<br>

还和疯长到肆无忌惮的杂草、树木展开搏斗！一共割掉了大约320升的草。<br>

车站前的超市居然倒闭了！只好每隔3天步行10公里去采购。<br>

就这样，しゃち（沙奇）度过了没有空调、规律又健康的生活。（しゃち）

{% legacy_image id="gamefreak-staff-c01e8eeddaf1" alt="カラシ" %}<br>

久违地去了阳光水族馆！<br>

虽然人很多，但馆内很凉快，<br>

看着悠然游动的鱼儿，整个人都被治愈了。（カラシ（卡拉希））

{% legacy_image id="gamefreak-staff-07b3a5396fa1" alt="ヒロ" %}<br>

去了年幼的大儿子一直想看的英雄秀！<br>

而且一共去了3次！<br>

另外还一起去看了等身大的高○达，<br>

这是一个被英雄们包围的夏天！<br>

能让父母和孩子一起开心，真是太棒了呢。<br>

不过话说回来，其实是家长玩得更开心……（ヒロ）

{% legacy_image id="gamefreak-staff-d03ced8cc346" alt="さとう" %}<br>

坐着宝可梦喷气客机去了日本海沿岸，吃了很多海鲜。<br>

我本来正怀着幸福的心情眺望着地平线，<br>

却遭到了鸢的袭击，真是倒了大霉。（さとう（佐藤））

{% legacy_image id="gamefreak-staff-c505828e65e1" alt="おせんべい" %}<br>

暑假里，久违地去爬了山。<br>

沿着登山道，看到了湿地、高山植物的花田等等，<br>

感受到了偶然在那里形成的自然之美，以及它的壮阔。<br>

天气也很帮忙，出了很多汗，所以在山顶喝的啤酒简直棒极了。<br>

（おせんべい）

{% legacy_image id="gamefreak-staff-57ddcfb7c8a9" alt="ジョニー" %}<br>

暑假里看了《夏日大作战》和剧场版《假面骑士》。<br>

《假面骑士》是和《侍战队真剑者》同场上映的，<br>

但第一次看的《侍战队真剑者》实在太有意思了，<br>

我感觉自己可能要时隔十几年再次迷上战队作品了。<br>

《夏日大作战》也很好看。<br>

走出电影院时，我有种刚去乡下亲戚家串过门的感觉。<br>

除此之外，还把祭典抽奖抽中的西瓜吃得一干二净，就这样啦——。（ジョニー（乔尼））

{% legacy_image id="gamefreak-staff-228248e61477" alt="エノキ" %}<br>

开始养猫了！<br>

我觉得全世界没有哪只猫比我家这孩子更可爱、更漂亮、更聪明！（エノキ（榎木））

{% legacy_image id="gamefreak-staff-470ddfd96dd9" alt="なぎー" %}<br>

这个夏天接连和伙伴们去了高原、山里和沼泽地旅行！<br>

高原有高原的，山里有山里的，各自都有独特的生物。<br>

它们行动敏捷，还有些家伙一兴奋过头，就会直接撞向人类！<br>

听说打倒危险的生物后，就能拿到钱和各种材料，<br>

所以我努力地打倒了好多！！<br>

一个人的话有些危险，但和伙伴一起就什么都做得到。<br>

和伙伴协力合作真的很重要呢。（なぎー（纳吉））

{% legacy_image id="gamefreak-staff-e9f38354a98f" alt="KAGE" %}<br>

回了趟老家，悠闲地度过了一段时间。<br>

有机会和高中时代的恩师、朋友久违地一起喝酒，<br>

聊起了令人怀念的往事，话题也越聊越热烈。我们互相分享近况，还热烈地<br>

谈起了今后的梦想。得到了非常多的力量。（KAGE（影））

{% legacy_image id="gamefreak-staff-eac4075086cb" alt="ほっしー" %}<br>

因为7月买了 iPhone 3G S，所以一会儿下载应用，一会儿编程，<br>

一会儿又摸来摸去，回过神来暑假就结束了。简直已经成了身体的一部分！（ほっしー（小星））

{% legacy_image id="gamefreak-staff-3220fb3479df" alt="スティック" %}<br>

回了趟位于鹿儿岛的老家。<br>

鹿儿岛有一座叫“樱岛”的活火山，<br>

最近它活动得格外频繁，连我逗留的时候，<br>

也曾经一天喷发3次。<br>

后来回到东京，竟然连续3天发生了地震，<br>

横跨日本列岛的地幔，今年是不是有点不妙啊。<br>

我开始担心起来，想着是不是该认真考虑一下防灾小物件之类的了。（スティック（斯蒂克））

{% legacy_image id="gamefreak-staff-9899debf1065" alt="っゃっゃ" %}<br>

嗨！我是っゃっゃ。<br>

今年刚成立的 GAME FREAK 摄影部，<br>

在暑假里开展了第二次活动。<br>

这次的主题是“拍下东京的夏日闪耀！”<br>

顶着烈日，我们不服暑热，去了浅草、滨离宫，<br>

还沿着东京湾一路咔嚓咔嚓地拍了起来。<br>

天气晴朗，街上闪闪发光的东西多得拍都拍不完。<br>

我们忘记了炎热，着迷地拍摄着闪耀的东京。<br>

阳光映照下的河岸、闪耀的高楼群、闪耀的摊主大叔额头上的汗。<br>

在我拍下的照片中，最闪耀的，<br>

还是摄影部成员们为了开心地拍下闪耀之物而露出的闪耀笑容。<br>

{% legacy_image id="gamefreak-staff-40a52891b071" alt="キラめきカメラ部" %}<br>

（っゃっゃ）

真是各有各的夏日乐趣呢——。<br>

カニ子这个夏天也经常出门，比如去旅行什么的，<br>

背景音乐大概是松崎茂那种感觉，度过了一个充满激情的美好夏天。<br>

我也打算把暑假收获的快乐放在心里，继续做一份充满激情的工作。

<br>
