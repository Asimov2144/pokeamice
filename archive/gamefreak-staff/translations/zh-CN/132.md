你好！我是负责招聘的さとう（佐藤）。

每天都在想着招聘新伙伴的我，<br>

最近稍微回想起了自己入职时的事情。<br>

其实，我从外部加入 GAME FREAK，已经是1年前的6月了。<br>

正好就是这个时候……哎呀，真让人怀念！

入职前我也纠结了很多，不过对我来说，最后起决定作用的是两点。<br>

一点是，只要自己主动，公司就愿意让我尝试各种事情的态度，<br>

另一点是，我在面试时遇到的、之后要一起工作的同事们。<br>

实际工作下来，我每天都切身体会到，<br>

当时的自己认为是“决定因素”的事情，果然没有错。

每个人在工作时想要珍惜的东西都不一样，<br>

但对我来说，那些东西正好存在于 GAME FREAK，我是这么想的。<br>

这应该就是所谓的“缘分”吧……

GAME FREAK 现在应届毕业生招聘和中途招聘都在进行，<br>

如果能让更多人觉得“说不定我们有缘！”我会非常高兴。

为了牵起这份缘分，先简单介绍一下招聘信息。

{% legacy_image id="gamefreak-staff-8acd5ff02a70" alt="採用担当の佐藤です" %}

首先是应届毕业生招聘，目前正在进行今年最后一轮的第二次募集。<br>

预计于2010年度毕业的朋友，欢迎一定来挑战一下。<br>

申请材料接收截止日期为2009年7月3日（星期五）。<br>

详情请参阅[应届毕业生招聘页面](http://www.gamefreak.co.jp/recruit/index.html)。

另外，中途招聘也在随时进行中！<br>

目前急需招聘的职位是平面设计师、程序员、<br>

声音创作者。<br>

详情也请在[中途招聘页面](http://www.gamefreak.co.jp/recruit/career.html)确认。

GAME FREAK 是一家怎样的公司，自己和这里有没有缘分，<br>

有些事情如果不亲自走进公司，可能也无法了解。<br>

我自己当时也是这样。<br>

我在招聘选拔期间来到 GAME FREAK，和员工聊了很多，然后决定入职。

对于正在考虑应聘的朋友，<br>

也希望大家一定能亲自来到公司，自己确认一下。

那么，期待大家来应聘！
