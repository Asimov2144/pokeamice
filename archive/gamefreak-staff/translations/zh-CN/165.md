你好，我是负责网站的涅罗莉卡。<br>

虽然寒假结束已经有一阵子了，但我们还是照例策划了假期结束后的特别企划<br>

“大家寒假都做了些什么？”于是我去问了问 GAME FREAK 的员工们！

{% legacy_image id="gamefreak-staff-eac4075086cb" alt="ほっしー" %}<br>

继夏天之后，我又用 iPhone 3G S 编程，<br>

还摸来摸去的，结果寒假就这么结束了。<br>

我已经无法离开 iPhone 活下去了！（ほっしー）

{% legacy_image id="gamefreak-staff-a55742a47d80" alt="マシュー" %}<br>

有了空闲时间，就读了读书，<br>

因为我是个喜欢待在室内的人，所以也尽量试着出门走走。<br>

走在路上时，只要有面带笑容的人从身边经过，我也会变得开心起来。<br>

我想，自己每天也要尽量保持笑容！（マシュー）

{% legacy_image id="gamefreak-staff-470ddfd96dd9" alt="なぎー" %}<br>

年末年初回老家去了。<br>

因为我把今年的目标之一定为“多读点书吧！”，所以马上就开始努力读书了。<br>

当然，今年也还是以下这个永久循环。<br>

“边读书边上网→边读书边玩 DS→边读书边上网……”<br>

也许什么都没进脑子，不过我确实读了书，对吧！？<br>

……可不能长成这样的成年人哦！（なぎー）

{% legacy_image id="gamefreak-staff-652d88b0431f" alt="ラッペン" %}<br>

我在零点去新年参拜了，不过今年除夕？元旦那天真是冷得不得了！<br>

参拜完之后，尽情享受了一场路边摊吃到撑之旅。<br>

炒面当然少不了，还在卖杏子糖的摊位买了好多装满李子的包装<br>

把手和嘴都染得通红，吃了个痛快！（ラッペン）

{% legacy_image id="gamefreak-staff-d03ced8cc346" alt="さとう" %}<br>

回北方老家的父母家去了。<br>

虽然过得很悠闲，<br>

但也有过被车站大楼里招呼客人的“生剥鬼”<br>

追着跑，感到有点害怕的时候。（さとう）

{% legacy_image id="gamefreak-staff-57ddcfb7c8a9" alt="ジョニー" %}<br>

我下定决心，年末不做大扫除就不能跨年！<br>

于是兴冲冲地打扫了起来。<br>

此外，除夕夜也和去年一样，<br>

跟朋友在家一边吃火锅，一边看红白歌会。<br>

大家热热闹闹地聊着平时不会聊的艺人之类的话题，<br>

悠闲自在地迎来了新年？。（ジョニー）

{% legacy_image id="gamefreak-staff-707010161046" alt="おにいさん" %}<br>

寒假里有一件事是我决定绝对要做到的……<br>

那就是时隔二十多年，再玩一次我第一次接触（玩到）的电视游戏主机<br>

《小太（当时：TOMY）》！<br>

我想那时候的我大概是小学四年级左右，<br>

就是想再一次感受当时沉迷于电视游戏的那一刻、那份感动。<br>

我压抑着迫不及待的心情，咔哒一声打开电源，标题画面出现的瞬间……<br>

那时的记忆苏醒了。<br>

是和朋友□□君为了争先后顺序吵架，最后不欢而散的悲伤记忆。（おにいさん）

{% legacy_image id="gamefreak-staff-58a67328cf84" alt="カニ子" %}<br>

熟人的孩子们带我一起去摘草莓了。<br>

因为平时没有机会和小孩子待在一起，<br>

他们吸收知识快得不得了、身体能力又强，让我十分惊讶。<br>

而且，面对那股精力充沛的孩子劲儿，<br>

能够以更快的势头迅速照顾好孩子的妈妈，也让我大吃一惊。<br>

妈妈真厉害！还有，现摘的草莓超级好吃！（カニ子）

{% legacy_image id="gamefreak-staff-c505828e65e1" alt="おせんべい" %}<br>

我开车了。<br>

平时大多是坐在桌前工作，所以想着做点平常不会做的事，<br>

就开车回了老家。<br>

单程四小时的路程，因为平时几乎不开车，所以在高速公路上<br>

既感到紧张，也欣赏着景色从城市变成乡村的变化，<br>

享受了一场小小的冒险。<br>

本来在乡下也有想做的事，可雪下得实在太大，<br>

结果几乎都待在家里读书了……。（おせんべい）

{% legacy_image id="gamefreak-staff-747a58bef9aa" alt="もりもと" %}<br>

带着六月出生的儿子去了妻子的老家鹿儿岛。<br>

儿子又是家里的第一个孙辈，自然被疼爱得不得了。<br>

家人还对岳父说：“你在自己孩子小时候，可没这么上心吧。”<br>

“孙子比孩子更可爱”的传言，说不定是真的。<br>

回程的飞机上，碰巧乘坐了宝可梦飞机。<br>

因为带着孩子，还拿到了皮卡丘束口袋哦！（もりもと）

对寒假大部分时间都卧病在床的涅罗莉卡来说，大家的寒假真是令人羡慕不已！<br>

虽然我现在已经完全康复了，但寒冷的日子还会持续一段时间，<br>
