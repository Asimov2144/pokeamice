好久不见。<br>

我这个大哥哥又来了。<br>

对着任天堂卡带的电路板部分呼一口气『呼——！』，<br>

就会变得更容易插进去，我这个大哥哥真的很想知道这是为什么。

这次想低调地聊聊任天堂游戏软件的形状。<br>

{% legacy_image id="gamefreak-staff-5b62f5ea0b00" alt="基本のカタチ" %}

原本只是为了保护游戏电路板，<br>

在当时被称作『卡带』的这个方形塑料部分。<br>

我想有很多人都知道，<br>

这些卡带各家公司都有各种各样的颜色和类型，<br>

这种其他游戏主机所没有的多样设计，<br>

也是任天堂收藏家们着迷的原因之一。

大约有一千种以上的卡带，绝大多数都是这种形状，<br>

{% legacy_image id="gamefreak-staff-aac52d9201d3" alt="基本のカタチ" %}

有双色设计的，<br>

{% legacy_image id="gamefreak-staff-f7b09d6623b0" alt="ツートーン" %}

有把公司名称做成浮雕的，<br>

{% legacy_image id="gamefreak-staff-94f3aa65bab1" alt="エンボス" %}

有做成闪亮镀层的，<br>

{% legacy_image id="gamefreak-staff-806d981f8cbb" alt="キラキラ" %}

有在中央装上发光二极管的（打开主机电源后会亮起红光），<br>

{% legacy_image id="gamefreak-staff-946f9d9c6160" alt="ダイオード" %}

还有内部完全透明的半透明款（前后也只有这一款软件采用了半透明设计），<br>

{% legacy_image id="gamefreak-staff-fa3170eccbd6" alt="半透明" %}

长条形的，<br>

{% legacy_image id="gamefreak-staff-4aafb71c5302" alt="縦長" %}

相当厚的类型也有，<br>

{% legacy_image id="gamefreak-staff-dace71b21627" alt="太め" %}

还有这么小的尺寸，<br>

{% legacy_image id="gamefreak-staff-93012ddbb2d4" alt="ちっちゃい" %}

插入口上带有盖子的，<br>

{% legacy_image id="gamefreak-staff-dfbc32ea03a5" alt="キャップつき" %}

还有形状稍微有些特别的，<br>

{% legacy_image id="gamefreak-staff-5a9079b6e3b7" alt="変わった形" %}

到了任天堂发展的后期，<br>

甚至还出现了让人忍不住怀疑“这是任天堂？”的设计。<br>

{% legacy_image id="gamefreak-staff-c9dd8c79be2c" alt="全体会" %}

就是这样，真的有非常多种形状，所以光是看着也很有意思呢？<br>

不过其实它们不只是有趣，在功能方面也经过了扎实的设计。<br>

卡带两侧做了凹凸处理，可以防止手指打滑，<br>

为了防止插反，也没有设计成正方形，而是做成了梯形。<br>

另外，卡带顶部开着的那个小小方孔，<br>

据说是为了让电路板散热，<br>

但我当时还是小学生，误以为那是用来穿绳子、挂在脖子上的，<br>

还记得自己曾经拼命地想把毛线穿进去。<br>

任天堂在这些与游戏无关的『形状』上所下的功夫，以及其中的趣味，<br>

或许也促成了它的爆炸性畅销呢。

那么，敬请期待下一回。
