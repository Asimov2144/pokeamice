初次见面，我是程序员タピオカ（塔皮奥卡）。<br>

今后请多关照。

那么。<br>

7月某日，休息日出去走了走。<br>

平时去公司上班时，我总是乘坐快车。<br>

那天也没有什么急事，<br>

于是换乘了准快车和普通车，坐在座位上一路来到东京市内。<br>

换乘不同的电车，感觉连看到的景色都变了。

{% legacy_image id="gamefreak-staff-420381599429" alt="" %}

我，タピオカ，是通过中途招聘来到 GAME FREAK 的程序员。<br>

在那之前，我也换过好几家公司。<br>

和电车一样，公司一变，眼前所见的景色也会改变。

虽说公司各不相同，<br>

但程序员的工作内容并没有太大变化。<br>

世上的程序员们经历过的那些辛苦事，<br>

在 GAME FREAK 也同样必须面对！

不过，工作内容虽然一样，名为 GAME FREAK 的这列“电车”<br>

却是乘坐感最舒服的。<br>

理由是……

**（1）一起乘车的人都很棒！**<br>

这里有充满干劲的人。<br>

这里有在遇到困难时会伸手相助的人。<br>

可以安心地全力工作！<br>

（这部分说出来有点不好意思，希望公司员工不要看到……）

**（2）机会很多！**<br>

有很多机会可以挑战自己想做的事。<br>

就算只拿宝可梦来举例，<br>

这也是一款包含大量要素的游戏，<br>

所以可以做各种各样的事情！

**（3）有很多愿意游玩的玩家！**<br>

能够制作出让许多玩家游玩的游戏，<br>

对创作者来说是无上的喜悦。<br>

当然，责任也会随之变得重大，但这份工作很有价值！

既然都能抵达同一个目的地，<br>

当然还是乘坐适合自己的电车比较好，对吧。

{% legacy_image id="gamefreak-staff-70f9ab9ccd68" alt="" %}

换乘 JR 山手线的电车后，在中途的车站随意下车，<br>

买到了胖丁和芝士蛋糕！<br>

相当美味！

{% legacy_image id="gamefreak-staff-645b1a93997e" alt="" %}<br>

又坐了一会儿电车，<br>

终于抵达了这次出门的目的地车站。

我，タピオカ，作为创作者前往目的地的旅程，<br>

自从登上名为 GAME FREAK 的电车后，<br>

仍然还在继续。

那么，对 GAME FREAK 抱有兴趣的各位社会人士！<br>
