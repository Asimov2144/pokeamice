你好！好久不见，我是カニ子（蟹子）。

那么，时间过得真快，我的试用期也结束了，正式成为一名正式员工，<br>

这周一，公司送给了我一样很棒的东西。

{% legacy_image id="gamefreak-staff-e1919b8aa798" alt="オムスター" %}

锵锵！<br>

我收到的东西，就是カニ子的名片。

名片上会写着名字，所以每个人的名片各不相同是理所当然的，<br>

但 GAME FREAK 的名片可不太一样。相当特别。

每个人的名片上，都会有一幅专门为其绘制的不同宝可梦插画！<br>

カニ子的宝可梦是多刺菊石兽。好可爱！

加入 GAME FREAK 的人，<br>

可以从宝可梦 红·绿中登场的<br>

151种宝可梦里选择一种，印在自己的名片上。<br>

规则是，不能选择已经被其他人选走的宝可梦。

这些插画是 GAME FREAK 的美术设计师<br>

专门为名片绘制的，<br>

因此是世界上独一无二的插画。

{% legacy_image id="gamefreak-staff-579ec37b1326" alt="みんなの名刺" %}

这是其他员工的名片。<br>

各有各的个性，很有意思！

顺便一提，目前还没有集齐151种名片。<br>

真期待新员工加入，集齐151种名片的那一天到来。<br>
