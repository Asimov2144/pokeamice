大家好，我是负责网站的妮洛莉卡。<br>

回过神来，已经是9月了呢。好快！<br>

这次为了惜别即将过去的夏天，我们要送上惯例栏目“大家，暑假都在做什么？”<br>

{% legacy_image id="gamefreak-staff-58a67328cf84" alt="カニ子" %}<br>

我去法国来了一趟独自旅行。<br>

不管去了什么地方，都努力和人家聊天，<br>

只要笑着打个招呼，对方也会露出笑容。<br>

法国的熟食真好吃呀——！（蟹子）<br>

{% legacy_image id="gamefreak-staff-9d412b073407" alt="フランスのおそうざい" %}

{% legacy_image id="gamefreak-staff-57ddcfb7c8a9" alt="ジョニー" %}<br>

我在暑假期间回了趟自己的国家。<br>

难得有这么长时间待在那里，几乎一直和家人黏在一起，<br>

身心都得到了大恢复？！<br>

另外，我还拍了婚礼前的婚纱照。<br>

既然是婚纱照，就按照摄影师的指示，<br>

安排了各种欢闹甜蜜的姿势和场景。<br>

我想之后应该会不好意思直视。（约翰尼）

{% legacy_image id="gamefreak-staff-eac4075086cb" alt="ほっしー" %}<br>

我去了澳门的赌场。<br>

因为赌场就在酒店里面，所以可以放心地玩。<br>

转眼间，几万、几十万日元的代币在眼前高速流动，<br>

那个空间既让人害怕，却又有那么一点吸引力。（星星）

{% legacy_image id="gamefreak-staff-470ddfd96dd9" alt="なぎー" %}<br>

我竟然把两趟旅行都安排在了暑假的最后一周！<br>

周二周三住在热海，专程去玩桌游，<br>

周四周五周六则去了青森，看白神山地和十和田湖！<br>

大海、山、湖泊、温泉，应有尽有的一周。<br>

平时做的是室内工作，已经很久没有尽情享受户外了。<br>

面对美妙的自然景色，我一直感动不已。<br>

……不过，难得最后一天是星期日，<br>

我却一直睡觉睡到了晚上。（凪）

{% legacy_image id="gamefreak-staff-d03ced8cc346" alt="さとう" %}<br>

我和老家的家人一起，爬了附近的山去看瀑布。<br>

有地下水流过的瀑布周围很凉快，绿色也格外鲜艳，<br>

治愈效果一级棒！！<br>

要是东京也有这样的地方，我肯定每天都去……。（佐藤）<br>
{% legacy_image id="gamefreak-staff-7244fc868ad5" alt="滝" %}

{% legacy_image id="gamefreak-staff-c01e8eeddaf1" alt="カラシ" %}<br>

这个夏天，我去了传闻中的水木茂大道！<br>

可能是因为《鬼太郎之妻》的人气，那里人多得不得了。<br>

听说数量惊人的妖怪雕像各自都有不同的福泽，<br>

一路上我又看又摸，尽情享受了一番！<br>

多亏妖怪的福泽焕然一新，从今天起我要努力工作！！<br>

↓因为不知怎么的很喜欢百目，所以只给它拍了手机照片，<br>

现在想想，早知道也该拍一下鬼太郎的……。（芥末）<br>

{% legacy_image id="gamefreak-staff-b03792966e7c" alt="百目" %}

{% legacy_image id="gamefreak-staff-d6ad55735aef" alt="えるかつ" %}<br>

艾尔卡茨去度蜜月啦！<br>

10天里逛了意大利、法国，外加德国，一共3个国家，<br>

玩得非常尽兴。<br>

坐了威尼斯的贡多拉，在卡普里岛进了蓝洞，<br>

还在佛罗伦萨爬上了乔托钟楼，在罗马把手伸进了真理之口。<br>

在法国还去了巴黎圣母院和圣米歇尔山，<br>

真是内容丰富的暑假。<br>

我非常喜欢披萨，所以一直津津有味地品尝着正宗披萨，<br>

但由于奶酪的味道实在太浓，到了旅行后半段，<br>

开始想念起和食了。（艾尔卡茨）

{% legacy_image id="gamefreak-staff-9070e2888ef2" alt="いっちー" %}<br>

我一直在玩“天下统一”。<br>

这是一个有着像牛郎一样发型的人，还有时不时说英语的人的游戏。<br>

我推荐玩家使用忍者！<br>

不管怎么说，骑马的方式实在太厉害了。<br>

不是骑在马上。只是站在马背上。还站得笔直。（笑）<br>

话说回来，自己跑说不定还更快呢……（一池）

{% legacy_image id="gamefreak-staff-33f960181f6a" alt="わも" %}<br>

为了观看高中棒球比赛，我和大学朋友去了甲子园？！<br>

两手拿着碎冰袋和团扇，一天看了4场比赛，卖力地加油。<br>

球员们的热情和球场的热气让我兴奋不已。高中棒球最高！<br>

之后回了趟老家，悠闲地住在亲戚家，<br>

还看宝冢的DVD看得流下了眼泪。<br>

最后喝了机场水龙头里流出来的宝矿力果汁，然后回到了东京。<br>

一边细细品味着爱媛的味道，今天也要努力工作！（和茂）<br>

{% legacy_image id="gamefreak-staff-2c1f8658805b" alt="甲子園" %}

看来大家都度过了各自想过的假期，真可谓是“各自的夏天”<br>

呢。<br>

接下来准备享受“晚来的暑假”的各位，还有<br>

“暑假已经结束了……”的各位，<br>

最近天气还会继续炎热，所以请务必注意预防中暑！
