我是入职还不到3个月的新人，叫じだぬ。<br>

不过话虽如此，毕竟我是中途入职，所以多少少了点新鲜感……<br>

我的工作是负责“信息管理”。<br>

关于信息管理的工作内容，请参阅[之前尤里的文章](http://www.gamefreak.co.jp/blog/staff/?p=98)。

这次，我想谈谈在我这个新人眼中的 GAME FREAK。<br>

入职这家公司以后，我每天都能感受到的是，<br>

所有成员都很重视“自主性”和“协作性”。

比如说，就算不是开会时间，公司各处也经常能看到<br>

开发成员们互相讨论。

公共的讨论空间、办公桌旁边，有时甚至就站着讨论。<br>

有时是面带严肃表情的讨论，<br>

有时是笑着交换意见，这些都是日常中很常见的景象。

{% legacy_image id="gamefreak-staff-ec21bbf42bc7" alt="打ち合わせ風景" %}

而且，我觉得不论在哪种场合，大家都有一个共同点，那就是<br>

每个人都有属于自己的想法：<br>

“我想做出这样的企划、这样的画面、这样的声音！”<br>

通过这样彼此碰撞个人的意见，<br>

创作出更加有趣的游戏。<br>

虽然我还是个新人，但我觉得这或许就是“GAME FREAK风格”。

じだぬ之所以想加入 GAME FREAK，<br>

当然是因为工作的内容，<br>

但也是因为通过事前收集信息和面试，我感受到了这样的“公司风气”。<br>

入职之后，我切实感受到，自己当时的感觉并没有错，<br>

最近尤其如此。

我虽然不是开发人员，<br>

但也会在“信息管理”这个岗位上努力进取，不输给大家，<br>

希望能把更多、更准确的信息传达给更多的人，<br>

让大家了解 GAME FREAK 作品的魅力。

不知不觉说得有点认真了，<br>

目前 GAME FREAK 正在招聘开发岗位，<br>

如果你也想在这样氛围的公司里工作，<br>

请务必去看看[中途招聘信息页面](http://www.gamefreak.co.jp/recruit/career.html)哦。

期待有一天能迎来后辈！<br>

那么，下回再见！

<br>
